[[Современные операционные системы (Windows)]]

==🔴**Брандмауэр Защитника Windows в режиме повышенной безопасности**== (Windows Defender Firewall with Advanced Security, WFAS) — это встроенный в операционные системы Windows межсетевой экран с контролем состояния сессий (Stateful Host-Based Firewall), тесно интегрированный со стеком TCP/IP ядра ОС и протоколами IPsec.

Windows Firewall является **stateful-экраном**. Это означает, что он не анализирует каждый пакет изолированно, а отслеживает контекст и фазы сетевых соединений в динамической **таблице состояний (State Table)**

- **Поведение при входящих подключениях (Inbound):**  
    Сервер ожидает пакет SYN. Брандмауэр сканирует входящие правила. Если совпадение найдено, сессия вносится в таблицу состояний. Ответные пакеты сервера (SYN-ACK, данные) выпускаются наружу **автоматически**, так как признаются частью установленной сессии (Established / Related).
    
- **Поведение при исходящих подключениях (Outbound):**  
    Когда локальное приложение инициирует сессию наружу, брандмауэр сверяет его с исходящими правилами. По умолчанию в Windows исходящий трафик разрешен. Как только пакет уходит, создается сессионная запись, и обратные входящие ответы от удаленного сервера пропускаются без необходимости создавать отдельное входящее правило.

Брандмауэр Windows адаптирует свой уровень строгости в зависимости от того, к какой сети подключен адаптер. За определение типа сети отвечает системная служба ==🔵**NLA (Network Location Awareness)**.==

1. **Domain Profile:** Включается **только тогда**, когда сетевой адаптер получает сетевой шлюз и успешно аутентифицирует контроллер домена Active Directory через безопасный RPC-вызов к службе Netlogon. Вручную назначить доменный профиль интерфейсу нельзя.
    
2. **Private Profile:** Выбирается администратором или пользователем для доверенных изолированных сегментов (домашняя сеть, технологический контур, защищенный сегмент за NAT). Включает сетевое обнаружение (Network Discovery).
    
3. **Public Profile:** Профиль по умолчанию для любых новых сетей. Сетевое обнаружение отключено, NetBIOS и входящий SMB заблокированы. Этот режим защищает мобильные компьютеры от сканирования и эксплойтов при подключении к публичному Wi-Fi.
