[[Языки программирования]]

В отличие от других команд, которые мы вводим в оболочке, для скрипта сначала необходимо создать файл с помощью любого текстового редактора. Файл должен иметь расширение`.sh`, которое является расширением по умолчанию для скриптов bash.
```
user@tryhackme:~$ nano first_script.sh
```

Каждый скрипт должен начинаться с шебанга. 
**Шебанг** — это комбинация символов, добавляемых в начало скрипта, начиная с `<script>`, за которым `#!`следует имя интерпретатора, используемого при выполнении скрипта. Поскольку мы пишем наш скрипт на bash, давайте определим его как интерпретатор в шебанге.
```
#!/bin/bash
```

==🔴Переменные==

Переменная хранит в себе значение. Предположим, вам нужно несколько раз использовать в скрипте сложные значения, такие как URL-адрес, путь к файлу и т. д. Вместо того чтобы запоминать и записывать их многократно, вы можете хранить их в переменной и использовать имя переменной везде, где это необходимо.

Приведённый ниже скрипт выводит на экран строку: "Привет, как тебя зовут?". Это делается с помощью `echo`команды. Вторая строка скрипта содержит код `read name`. `read`используется для получения ввода от пользователя, а `name`— это переменная, в которой будет храниться этот ввод. Последняя строка использует `echo`для отображения приветственной строки для пользователя вместе с его именем, хранящимся в переменной.

```
# Defining the Interpreter 
#!/bin/bash
echo "Hey, what’s your name?"
read name
echo "Welcome, $name"
```

Чтобы выполнить скрипт, сначала необходимо убедиться, что у скрипта есть права на выполнение. Чтобы предоставить скрипту эти права, можно ввести следующую команду в терминале:
```
user@tryhackme:~$ chmod +x first_script.sh
```

Теперь, когда скрипт получил права на выполнение, используйте `./`перед именем скрипта, чтобы запустить его. Мы используем`./`перед именем скрипта, чтобы запустить его, вместо того, чтобы вводить имя скрипта напрямую, потому что `./` это указывает оболочке выполнить файл, находящийся в текущем каталоге. Если вы не определите `./` перед именем скрипта, оболочка будет искать скрипт в переменной среды PATH (которая содержит все каталоги, кроме текущего), и она не найдет определенный скрипт ни в одном из этих каталогов и выдаст ошибку. Ниже показан скрипт, в котором мы использовали переменные:

```
User@ubuntu:~$ ./first_script.sh
Hey, What's your name?
John
Welcome, John
```

==🔴Циклы==

Цикл, как следует из названия, — это повторяющийся процесс.
```
# Defining the Interpreter 
#!/bin/bash
for i in {1..10};
do
echo $i
done
```

В первой строке находится переменная `i`, которая будет перебирать значения от 1 до 10 и каждый раз выполнять приведенный ниже код. `do`обозначает начало цикла, а `done`обозначает его конец. Между ними должен быть написан код, который мы хотим выполнить в цикле. Цикл for будет брать каждое число в скобках и присваивать его переменной `i`на каждой итерации. `echo $i`Значение этой переменной будет отображаться на каждой итерации.

==🔴Условные операторы==
Условные операторы — важная часть скриптинга. Они позволяют выполнить определенный код только тогда, когда выполняется условие; в противном случае можно выполнить другой код.
```
# Defining the Interpreter 
#!/bin/bash
echo "Please enter your name first:"
read name
if [ "$name" = "Stewart" ]; then
        echo "Welcome Stewart! Here is the secret: THM_Script"
else
        echo "Sorry! You are not authorized to access the secret."
fi
```

Приведённый выше скрипт принимает имя пользователя в качестве входных данных и сохраняет его в переменной. 
Условное выражение начинается с if и сравнивает значение этой переменной со строкой Stewart; если совпадение найдено, пользователю будет показан секрет, в противном случае — нет. fi используется для завершения условия.

==🔴Комментарии==
Иногда код может быть очень длинным. В этом случае код может запутать вас, когда вы посмотрите на него спустя некоторое время или поделитесь им с кем-то. Простой способ решить эту проблему — использовать комментарии в разных частях кода. Комментарий — это предложение, которое мы пишем в коде просто для лучшего понимания. Он пишется с помощью символа #, за которым следует пробел и предложение, которое вам нужно написать.
