[[Языки программирования]]

==🔴JavaScript (JS)== — популярный скриптовый язык, позволяющий веб-разработчикам добавлять интерактивные функции на веб-сайты, содержащие HTML и CSS (стили).

JavaScript — это **интерпретируемый** язык, то есть код выполняется непосредственно в браузере без предварительной компиляции.

JavaScript в основном выполняется на стороне клиента, что упрощает проверку и взаимодействие с HTML непосредственно в браузере.

==🔵***Переменные***== — это контейнеры, позволяющие хранить в них значения данных. Как и в любом другом языке, переменные в JavaScript похожи на контейнеры для хранения данных.

В JavaScript существует три способа объявления переменных: `var`,`let` и `const`. В то время как `var` имеет область видимости функции, `let` и `const` имеют область видимости блока, что обеспечивает лучший контроль над видимостью переменных внутри конкретных блоков кода.

В JavaScript ==🔵типы данных== определяют тип значения, которое может содержать переменная. Примеры включают `string`, `number`, `boolean`, `null`, `undefined` и `object` (для более сложных данных, таких как массивы или объекты).

==🔵Функция== представляет собой блок кода, предназначенный для выполнения конкретной задачи. Внутри функции группируются фрагменты кода, которые должны выполнять схожие задачи.
```
   <script>
        function PrintResult(rollNum) {
            alert("Username with roll number " + rollNum + " has passed the exam");
            // any other logic to display the result
        }

        // prepare an array of roll numbers (data)
        const rollNumbers = [101, 102, 103];

        // Note: We only have 3 roll numbers, so after i = 2, rollNumbers[i] becomes undefined

        for (let i = 0; i < 100; i++) {
            PrintResult(rollNumbers[i]);
        }
    </script>
```

==🔵Циклы==
Циклы позволяют выполнять блок кода несколько раз, пока выполняется условие `true`. Распространенные циклы в JavaScript — это циклы `for`, `while,`и `do...while`, которые используются для повторения задач.

В веб-разработке ==🔵цикл «запрос-ответ»== — это когда браузер пользователя (клиент) отправляет запрос веб-серверу, а сервер отвечает запрошенной информацией. Это может быть веб-страница, данные или другие ресурсы

==🔴Внутренний JavaScript==

Внутренний JavaScript вставляется непосредственно в HTML-документ. 
Скрипт вставляется между `<script>`тегами. Эти теги можно размещать внутри `<head>`раздела, обычно используемого для скриптов, которые необходимо загрузить до отображения содержимого страницы, или внутри `<body>`раздела, где скрипт может использоваться для взаимодействия с элементами по мере их загрузки на веб-странице.

JavaScript взаимодействует с HTML, выбирая элемент, например ( **\<p> с id="result"** ) и обновляя его содержимое с помощью тега `document.getElementById("result").innerHTML.` Этот встроенный JavaScript выполняется при загрузке HTML-файла браузером.

==🔴Внешний JavaScript==

Использование внешнего JS-кода предполагает создание и хранение JS-кода в отдельном файле с  `.js` расширением.
Внешний JS-файл может храниться на том же веб-сервере, что и HTML-документ, или на внешнем веб-сервере, например, в облаке.

==🟣Проверка== внутреннего или внешнего JavaScript

При тестировании веб-приложения на проникновение важно проверить, использует ли веб-сайт внутренний или внешний JavaScript. Это легко проверить, просмотрев исходный код страницы.

Одна из главных целей JavaScript — предоставление ==🔵диалоговых окон== для взаимодействия с пользователями и динамического обновления контента на веб-страницах.

JS предоставляет встроенные функции, такие как alert`,`prompt`и`confirm, для облегчения этого взаимодействия. Эти функции позволяют разработчикам отображать сообщения, собирать ввод и получать подтверждение от пользователя. Однако, если эти функции не реализованы безопасно, злоумышленники могут использовать их для осуществления атак, таких как межсайтовый скриптинг (XSS).

==🔵Alert==
Функция оповещения отображает сообщение в диалоговом окне с `OK`кнопкой, обычно используемой для передачи информации или предупреждений пользователям.

==🔵Prompt==
Функция prompt отображает диалоговое окно, запрашивающее у пользователя ввод. Она возвращает введенное значение, когда пользователь нажимает `OK`, или null, если пользователь нажимает `Cancel`.

==🔵Confrim==
Функция подтверждения отображает диалоговое окно с сообщением и двумя кнопками: `OK` и `Cancel`. Она возвращает true, если пользователь нажимает `OK` и false, если пользователь нажимает `Cancel`.

***Как хакеры используют эту функциональность***
Представьте, что вы получили электронное письмо от незнакомца с прикрепленным HTML-файлом. Файл выглядит безобидным, но при открытии вы обнаружите JavaScript, который нарушает работу вашего браузера.

Управление потоком выполнения в JavaScript относится к порядку выполнения операторов и блоков кода в зависимости от определенных условий. JS предоставляет несколько структур управления потоком выполнения, таких как операторы `if-else`, `switch`операторы  для принятия решений и циклы, такие как `for`, `while` и,`do...while` для повторения действий.

Одним из наиболее часто используемых ==🔵условных операторов== являются `if-else` операторы, которые позволяют выполнять различные блоки кода в зависимости от того, выполняется ли условие `true`или нет `false`.

==🔴Минификация в JavaScript== — это процесс сжатия JS-файлов путем удаления всех ненужных символов, таких как пробелы, переносы строк, комментарии и даже сокращение имен переменных. Это помогает уменьшить размер файла и улучшить время загрузки веб-страниц, особенно в производственной среде. Минифицированные файлы делают код более компактным и сложным для чтения человеком, но при этом они функционируют точно так же.

Аналогичным образом, ==🔴**обфускация**== часто используется для того, чтобы сделать JavaScript более сложным для понимания путем добавления нежелательного кода, переименования переменных и функций в бессмысленные имена и даже вставки фиктивного кода.

Мы также можем деобфусцировать обфусцированный код с помощью онлайн-инструментов.

***Избегайте использования только клиентской проверки.***

Одна из основных функций JavaScript — это проверка данных на стороне клиента. Разработчики иногда используют её для проверки форм и полностью полагаются на неё, что не является хорошей практикой. Поскольку пользователь может **отключить/изменить** JavaScript на стороне клиента, проверка данных на стороне сервера также необходима.

***Воздержитесь от добавления ненадежных библиотек.***

Как обсуждалось в предыдущих заданиях, JavaScript позволяет включать любые другие JS-скрипты, используя `src`атрибут внутри `script`тега. Но задумывались ли вы о том, является ли подключаемая библиотека из надежного источника? Злоумышленники загрузили в интернет множество библиотек с названиями, похожими на названия легитимных. Поэтому, если вы бездумно включите вредоносную библиотеку, вы подвергнете свое веб-приложение угрозам.

***Избегайте закодированных секретов.***

Никогда не вставляйте конфиденциальные данные, такие как **ключи API** , **токены доступа** или **учетные данные** , непосредственно в код JavaScript, поскольку пользователь может легко проверить исходный код и получить пароль

***Сведите к минимуму и обфусцируйте свой JavaScript-код***

Минимизация и обфускация JS-кода уменьшают его размер, улучшают время загрузки и затрудняют понимание логики кода злоумышленниками. Поэтому всегда  **минимизируйте**  и  **обфусцируйте**  код при его использовании в продакшене. Злоумышленник в конечном итоге сможет провести обратное проектирование, но для получения исходного кода потребуется как минимум определённые усилия.
