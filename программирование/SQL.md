[[Языки программирования]]

***SQL*** — это язык программирования, который можно использовать для запроса, определения и обработки данных, хранящихся в реляционной базе данных. 

==🔴**СОЗДАТЬ БАЗУ ДАННЫХ**==

Если необходима новая база данных, первым шагом будет её создание. Это можно сделать в SQL с помощью `CREATE DATABASE`оператора. Синтаксис выглядит следующим образом:
```
mysql> CREATE DATABASE database_name;
```

==🔴**ПОКАЗАТЬ БАЗЫ ДАННЫХ**==

Теперь, когда мы создали базу данных, мы можем просмотреть её, используя `SHOW DATABASES.`

==🔴**ИСПОЛЬЗОВАНИЕ БАЗЫ ДАННЫХ**==

Чтобы установить только что созданную базу данных в качестве активной, выполните `USE`.

==🔴**Удалить базу данных**==

Когда база данных больше не нужна (возможно, она была создана для тестирования или больше не требуется), её можно удалить с помощью `DROP`соответствующего оператора.

==🔴**СОЗДАТЬ ТАБЛИЦУ**==

Следуя логике операторов базы данных, создание таблиц также осуществляется с помощью `CREATE`оператора
```
mysql> CREATE TABLE example_table_name (
    example_column1 data_type,
    example_column2 data_type,
    example_column3 data_type
);    
```

Подобно тому, как мы можем вывести список баз данных с помощью оператора SHOW, мы также можем вывести список таблиц в нашей текущей активной базе данных.
```
mysql> SHOW TABLES;
```

Чтобы узнать, какие столбцы содержатся в таблице (и каков их тип данных), мы можем описать их с помощью `DESCRIBE`команды (которую также можно сократить до `DESC`)

После создания таблицы может возникнуть ситуация, когда ваши потребности в наборе данных изменятся, и вам потребуется изменить таблицу. Это можно сделать с помощью `ALTER`.

Аналогично удалению базы данных, вы также можете удалить таблицы с помощью `DROP`оператора

==🔴**Аббревиатура CRUD**== расшифровывается как **Create** (создать), **Read (** прочитать), **Update** (обновить) и **Delete (** удалить) и считается основными операциями в любой системе, управляющей данными.

Операция ==🟠**Create**== создаст новые записи в таблице. В MySQL это можно сделать с помощью оператора `INSERT INTO`, как показано ниже.
```
mysql> INSERT INTO books (id, name, published_date, description)
    VALUES (1, "Android Security Internals", "2014-10-14", "An In-Depth Guide to Android's Security Architecture");

Query OK, 1 row affected (0.01 sec)
```

Операция ==🟠**чтения**==, как следует из названия, используется для чтения или извлечения информации из таблицы. С помощью этого оператора можно получить доступ к столбцу или ко всем столбцам таблицы `SELECT`
```
mysql> SELECT * FROM books;
```

Операция ==🟠**обновления**== изменяет существующую запись в таблице, и `UPDATE`для этого можно использовать тот же оператор.
```
mysql> UPDATE books 
	SET description = "An In-Depth Guide to Android's Security Architecture."
	WHERE id = 1;
```

Операция ==🟠**удаления**== удаляет записи из таблицы. Этого можно добиться с помощью `DELETE`соответствующего оператора.

-  Условие `FROM` используется для указания таблицы, к которой мы обращаемся с помощью нашего оператора
 - `WHERE`условие, которое определяет, какие записи следует использовать.
 - `DISTINCT`пункт используется для предотвращения появления дублирующихся записей при выполнении запроса, возвращая только уникальные значения.
 - `GROUP BY`пункт объединяет данные из нескольких записей и **группирует** результаты запроса в столбцы.
 - `ORDER BY`пункт можно использовать для сортировки записей, возвращаемых запросом, в порядке возрастания (ASC) или убывания (DESC).
 - `HAVING`пункт используется вместе с другими пунктами для фильтрации групп или результатов записей на основе условия.

==🔴Операторы==

 - `LIKE`оператор обычно используется в сочетании с условиями, например, `WHERE`для фильтрации по определенным шаблонам в столбце.
 - Оператор `AND`использует несколько условий в запросе и возвращает значение, `TRUE`если все они истинны.
 - Оператор `OR`объединяет несколько условий в запросах и возвращает значение, `TRUE`если выполняется хотя бы одно из этих условий.
 - `NOT`оператор инвертирует значение логического оператора, позволяя исключить определенное условие.
-  `BETWEEN`оператор позволяет проверить, находится ли значение в заданном **диапазоне**.
- Оператор `=` (равенство) сравнивает два выражения и определяет, равны ли они, или же проверяет, совпадает ли значение одного выражения с другим в определенном столбце.
- Оператор `!=`(не равно) сравнивает выражения и проверяет, не равны ли они; он также проверяет, отличается ли значение от значения в столбце.
- Оператор `<` (меньше) проверяет, меньше ли выражение с заданным значением, чем предоставленное.
- Оператор `>`"больше" проверяет, превышает ли выражение с заданным значением предоставленное значение.
- Оператор `<=`(меньше или равно) проверяет, меньше ли или равно заданное значение выражения. С другой стороны, `>=` оператор (больше или равно) проверяет, больше ли или равно заданное значение выражения.

==🔴Функции==
==🟠Строковые функции:== 

- функция CONCAT() используется для сложения двух или более строк. Она полезна для объединения текста из разных столбцов.
- функция GROUP_CONCAT() может помочь нам объединить данные из нескольких строк в одно поле.
- функция SUBSTRING() извлекает подстроку из строки в запросе, начиная с заданной позиции. Длину этой подстроки также можно указать.
- функция LENGTH() возвращает количество символов в строке, включая пробелы и знаки препинания.

==🟠Агрегатные функции==

- функция COUNT() возвращает количество записей в выражении
- функция SUM() суммирует все значения (кроме NULL) заданного столбца.
- функция MAX() вычисляет максимальное значение в заданном столбце в выражении.
- функция MIN() вычисляет минимальное значение в заданном столбце в выражении.
