[[SOC]]

Если злоумышленник успешно обходит брандмауэр через соединение, выглядящее легитимным, и затем совершает какие-либо вредоносные действия внутри сети, должна быть система, позволяющая своевременно это обнаружить. Для этой цели существует решение для обеспечения безопасности внутри сети. Это решение известно как ==🔴`Intrusion Detection System (IDS)`.==

Системы обнаружения вторжений (IDS) могут быть развернуты следующими способами:

- **Система обнаружения вторжений на хост (HIDS)** Решения IDS, устанавливаемые на хостах, монтируются индивидуально на каждом хосте и отвечают только за обнаружение потенциальных угроз безопасности, связанных с конкретным хостом. Они обеспечивают детальное отображение активности хоста. Однако управление системами обнаружения вторжений на хостах может быть сложной задачей в больших сетях, поскольку они ресурсоемки и требуют управления на каждом хосте.
    
- **Система обнаружения вторжений в сеть (NIDS)** Сетевые системы обнаружения вторжений (IDS ) играют решающую роль в выявлении потенциально вредоносной активности во всей сети, независимо от конкретных хостов. Они отслеживают сетевой трафик всех задействованных хостов для обнаружения подозрительной активности. Они обеспечивают централизованное представление всех обнаруженных событий во всей сети.

==🔵Режимы обнаружения==

- **Системы обнаружения вторжений на основе сигнатур:** Ежедневно происходит множество атак. Каждая атака имеет свой уникальный шаблон, известный как сигнатура. Эти сигнатуры сохраняются системами обнаружения вторжений в их базах данных, так что если подобная атака повторится в будущем, она будет обнаружена по сигнатуре и сообщена администраторам безопасности для принятия мер. Чем сильнее база данных сигнатур системы обнаружения вторжений, тем эффективнее она будет обнаруживать известные угрозы. Однако системы обнаружения вторжений на основе сигнатур не способны обнаруживать атаки нулевого дня. Атаки нулевого дня не имеют предыдущих сигнатур (шаблонов) и не сохраняются в базах данных системы обнаружения вторжений. Поэтому системы обнаружения вторжений на основе сигнатур могут обнаруживать только те атаки, которые произошли ранее, и их сигнатуры (шаблоны) сохраняются в базе данных.
	
- **Системы обнаружения вторжений на основе анализа аномалий:** Этот тип систем обнаружения вторжений сначала изучает нормальное поведение (базовый уровень) сети или системы и выполняет обнаружение любых отклонений от нормального поведения. Системы обнаружения вторжений на основе анализа аномалий также могут обнаруживать атаки нулевого дня, поскольку они не полагаются на доступные сигнатуры для обнаружения. Они обнаруживают аномалии внутри сети или системы, сравнивая текущее состояние с нормальным поведением (базовым уровнем). Однако этот тип систем обнаружения вторжений может генерировать много ложных срабатываний (помечая безобидные действия как вредоносные), поскольку природа большинства легитимных программ совпадает с вредоносными. Системы обнаружения вторжений на основе анализа аномалий пометят их как вредоносные и будут считать, что любое необычное поведение является вредоносным.
	
- **Гибридная система обнаружения вторжений (IDS):** Гибридная система IDS сочетает в себе методы обнаружения, основанные на сигнатурах, и методы обнаружения, основанные на аномалиях, чтобы использовать преимущества каждого подхода. Некоторые известные угрозы могут уже иметь определенные сигнатуры в базе данных IDS; в этом случае гибридная система IDS будет использовать метод обнаружения, основанный на сигнатурах. Если она обнаружит новую угрозу, она может использовать метод обнаружения, основанный на аномалиях.
