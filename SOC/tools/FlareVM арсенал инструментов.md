 **FlareVM**, или « **Криминалистика, логический анализ и обратное проектирование** », представляет собой всеобъемлющий и тщательно подобранный набор специализированных инструментов, разработанных специально для удовлетворения потребностей реверс-инженеров, аналитиков вредоносного ПО, специалистов по реагированию на инциденты, криминалистов и специалистов по тестированию на проникновение. 

 ==🟣Обратное проектирование и отладка==

 ***Отладка*** — это выявление ошибок, понимание причин их возникновения и исправление кода для их предотвращения.

- **Гидра**- Разработанный АНБ пакет программного обеспечения для обратного проектирования с открытым исходным кодом.  
- **x64dbg** — отладчик с открытым исходным кодом для бинарных файлов в форматах x64 и x32.  
- **OllyDbg** — отладчик для обратного проектирования на уровне ассемблера.  
- **Radare2** — сложная платформа с открытым исходным кодом для обратного проектирования.
- **Binary Ninja** — инструмент для дизассемблирования и декомпиляции бинарных файлов.  
- **PEiD** — инструмент для обнаружения упаковщиков, криптографов и компиляторов.

==🟣Дизассемблеры и декомпиляторы==

Дизассемблеры и декомпиляторы — важнейшие инструменты анализа вредоносного ПО. Они помогают аналитикам понять поведение, логику и поток управления вредоносного ПО, разбивая их на более понятный формат. Инструменты, упомянутые ниже, обычно используются в этой категории.

- **CFF Explorer** - Редактор, предназначенный для анализа и редактирования файлов Portable Executable (PE).
- **Hopper Disassembler** — отладчик, дизассемблер и декомпилятор.
- **RetDec** — декомпилятор машинного кода с открытым исходным кодом.

==🟣Статический и Динамический анализ==

- **Process Hacker** — сложный редактор памяти и наблюдатель за процессами.
- **PEview** — портативная программа для просмотра исполняемых файлов (PE) и их анализа.
- **Dependency Walker** — инструмент для отображения зависимостей исполняемого файла.DLLзависимости
- **DIE (Detect It Easy)** — инструмент для обнаружения упаковщиков, компиляторов и криптографов.

Цифровая криминалистика включает в себя сбор, анализ и сохранение цифровых доказательств из различных источников, таких как компьютеры, сети и устройства хранения данных. В то же время, реагирование на инциденты сосредоточено на обнаружении, локализации, устранении и восстановлении после кибератак. Инструменты, упомянутые ниже, обычно используются в этой категории.

- **Volatility** - Структура анализа дампов памяти для криминалистической экспертизы памяти.
- **Rekall** — платформа для анализа памяти в рамках реагирования на инциденты.
- **FTK Imager** — инструменты для получения и анализа образов дисков в целях криминалистики.

Анализ сетей включает в себя различные методы и приемы изучения и анализа сетей с целью выявления закономерностей, оптимизации производительности и понимания базовой структуры и поведения сети.

- **Wireshark** — анализатор сетевых протоколов для записи и анализа трафика.  
- **Nmap**— Инструмент для обнаружения уязвимостей и построения сетевых карт.  
- **Netcat** — полезный инструмент для чтения и записи данных по сетевым соединениям.

Анализ файлов — это метод, используемый для проверки файлов на наличие потенциальных угроз безопасности и обеспечения надлежащих прав доступа к файлам.

- **FileInsight** — программа для просмотра и редактирования бинарных файлов.
- **Hex Fiend** — лёгкий и быстрый шестнадцатеричный редактор.
- **HxD** — программа для просмотра и редактирования бинарных файлов с помощью шестнадцатеричного редактора.

Пакет Sysinternals Suite — это набор передовых системных утилит, разработанных для того, чтобы помочь ИТ-специалистам и разработчикам управлять, устранять неполадки и диагностировать системы Windows.

- **Autoruns** — показывает, какие исполняемые файлы настроены для запуска во время загрузки системы.
- **Process Explorer** — предоставляет информацию о запущенных процессах.
- **Монитор процессов** — отслеживает и регистрирует активность процессов/потоков в режиме реального времени.

==🔴Монитор процессов (Procmon)==

Мощный инструмент для Windows, разработанный для регистрации проблем с приложениями вашей системы. Он позволяет  **просматривать, записывать и отслеживать активность системы и файлов Windows в режиме реального времени** . Process Monitor полезен для  **отслеживания активности системы, особенно в контексте исследования вредоносных программ, устранения неполадок и криминалистических расследований** . Он ведет мониторинг в режиме реального времени, файловая система, реестр и активность потоков/процессов.

![[Pasted image 20261114235135.png]]

Согласно этой записи в журнале, служба подсистемы локального органа безопасности (LSASS)- связанный процесс lsass.exe успешно прочитал файл. LSASS обрабатывает аутентификацию и часто взаимодействует с важными системными файлами, такими как lsasrv.dll(Служба локального сервера управления безопасностью).

Хотя это стандартный системный процесс, LSASS может стать целью атак с целью кражи учетных данных, если вы изучаете журналы на предмет признаков вредоносной активности. Mimikatz и другие инструменты часто пытаются получить доступ к памяти LSASS. В таких ситуациях следует следить за любой дополнительной подозрительной активностью, связанной с LSASS, например, за странными шаблонами доступа или процессами, читающими или записывающими данные в lsass.exe.

==🟣Process Explorer (Procexp)==

Process Explorer предоставляет подробную информацию об активных процессах, работающих на вашем компьютере. Он позволяет углубиться во внутреннюю работу вашей системы, предоставляя исчерпывающий список запущенных процессов и связанных с ними учетных записей пользователей.

==🟣HxD== — это быстрый и гибкий шестнадцатеричный редактор для редактирования файлов, памяти и дисков любой емкости. Он может применяться в криминалистике, восстановлении данных, отладке и точной обработке двоичных данных. Важные функции включают просмотр содержимого файлов и памяти, редактирование, поиск и сравнение шестнадцатеричных данных.

![[Pasted image 20261114235413.png]]

==🟣CFF Explorer==

С помощью исчерпывающей информации о файлах, предоставляемой CFF Explorer, следователи могут генерировать хеши файлов для проверки целостности, аутентифицировать источник системных файлов и подтверждать их достоверность (например, путем поиска необычных изменений). Это важно знать при анализе вредоносного ПО, поскольку опасный код может быть скрыт в измененных системных файлах.

![[Pasted image 20261114235538.png]]

==🟣PEStudio==

Статический анализ, или изучение свойств исполняемых файлов без их запуска, выполняется с помощью PEstudio. Эта функция полезна в ряде ситуаций. PEstudio предоставляет разнообразную информацию о файле, не подвергая пользователей опасности его запуска, что помогает выявлять исполняемые файлы, которые кажутся подозрительными или опасными.

![[Pasted image 20261114235805.png]]

==🟣FLOSS==

Используя передовые методы статического анализа, FLARE Obfuscated String Solver (FLOSS, ранее FireEye Labs Obfuscated String Solver) автоматически извлекает и деобфусцирует все строки из вредоносных программ. Подобно strings.exe, он может улучшить базовый статический анализ неизвестных бинарных файлов. FLOSS также включает в себя дополнительные скрипты Python в каталоге скриптов, которые можно использовать для загрузки результатов работы скрипта в другие программы, такие как IDA Pro или Binary Ninja.
