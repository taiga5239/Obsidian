==🔵OpenVAS== — это решение с открытым исходным кодом для оценки уязвимостей, разработанное компанией Greenbone Security. Оно предлагает базовые функции, включая сканирование известных уязвимостей через свою базу данных. Оно менее функционально, чем коммерческие инструменты, но позволяет оценить возможности полноценного сканера уязвимостей. OpenVAS полезен для небольших организаций и отдельных систем.

Установка OpenVAS может быть очень сложной, так как у него много зависимостей. Для установки OpenVAS мы будем использовать Docker.

После завершения процесса установки вы можете получить доступ к веб-интерфейсу OpenVAS, открыв любой из ваших браузеров и введя в адресную строку следующий текст:
`https://127.0.0.1`

Это перенаправит вас на страницу входа в OpenVAS.  После ввода правильных учетных данных откроется следующая панель управления. Эта панель предоставляет полный обзор всех ваших сканирований уязвимостей:

==🔴Выполнение сканирования уязвимостей==

Первым шагом будет создание задачи в панели управления OpenVAS. Мы заполним данные для этой задачи и выполним ее для запуска сканирования уязвимостей.

Нажмите на опцию «Задачи», расположенную в разделе «Сканирования» на панели управления:

Вы попадете на страницу, где отображаются все запущенные задачи. На этой странице мы не увидим ни одной задачи, поскольку еще не выполняли никаких сканирований. Чтобы создать задачу, нажмите на значок звездочки, а затем на опцию «Новая задача», как показано на скриншоте:
![[Pasted image 20261112144022.png]]

Введите название задачи и нажмите кнопку «Сканировать цели», как показано на скриншоте:
![[Pasted image 20261112144038.png]]

Введите имя лабораторного компьютера и его IP-адрес, затем нажмите «Создать»:
![[Pasted image 20261112144049.png]]

Вам будет доступно несколько вариантов сканирования. Каждый вариант сканирования имеет свой объем данных; вы можете изучить подробности каждого типа сканирования и выбрать подходящий, а затем нажать кнопку «Создать»:
![[Pasted image 20261112144101.png]]

Задача создана и отобразится на панели задач. Чтобы запустить сканирование, нажмите кнопку воспроизведения в разделе «Действия» задачи:
![[Pasted image 20261112144113.png]]

Сканирование займет несколько минут. После завершения сканирования вы увидите его статус «Выполнено». На панели задач отобразятся числовые значения, указывающие на серьезность обнаруженных уязвимостей. Чтобы просмотреть подробности сканирования, необходимо щелкнуть по названию задачи:
![[Pasted image 20261112144125.png]]

Чтобы просмотреть подробную информацию обо всех уязвимостях, обнаруженных в ходе сканирования, вы можете щелкнуть по числу, указывающему количество обнаруженных уязвимостей на исследуемом хосте:
![[Pasted image 20261112144137.png]]

Теперь у нас есть список всех обнаруженных в этой системе уязвимостей и их степень серьезности. Мы также можем щелкнуть по любой из них, чтобы увидеть более подробную информацию:
![[Pasted image 20261112144148.png]]
