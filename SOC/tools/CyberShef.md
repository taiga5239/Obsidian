[[tools_analysis]]

***CyberChef*** — это простое и интуитивно понятное веб-приложение, разработанное для выполнения различных задач в «киберпространстве» в вашем веб-браузере.

CyberChef состоит из четырех разделов. Каждый из них включает в себя различные компоненты или функции.

Это следующие районы:
1. Operations
2. Recipe
3. Input
4. Output

![[Pasted image 20261112221124.png]]

==🟣Operations Area==

Это практичное и всеобъемлющее хранилище всех разнообразных операций, которые может выполнять CyberChef. Эти операции тщательно систематизированы, предоставляя пользователям удобный доступ к различным возможностям. Пользователи могут использовать функцию поиска для быстрого поиска конкретных операций, повышая свою эффективность и производительность.

В качестве альтернативы, вы можете напрямую проверить, как работают операции, наведя курсор на конкретную операцию. Это должно показать вам пример или описание и ссылку на Википедию.

==🟣Recipe==

Это считается сердцем инструмента. В этой области вы можете легко выбирать, упорядочивать и точно настраивать операции в соответствии со своими потребностями. Здесь вы берете управление на себя, точно и целенаправленно определяя аргументы и параметры каждой операции. Область рецептов — это специально отведенное пространство для выбора и упорядочивания конкретных операций, а затем определения их соответствующих аргументов и параметров для дальнейшей настройки их поведения. В области рецептов вы можете перетаскивать операции, которые хотите использовать, и указывать аргументы и параметры.

В число функций входят следующие:

- `Save recipe`Эта функция позволяет пользователю сохранять выбранные операции.
- `Load recipe`Позволяет пользователю загружать ранее сохраненные рецепты.
- `Clear Recipe`Эта функция позволит пользователям очищать выбранный рецепт во время использования.

В нижней части изображения выше находится кнопка `BAKE!`. Она обрабатывает данные в соответствии с заданным рецептом.

Кроме того, вы можете поставить галочку в `Auto Bake`соответствующем поле. Эта функция позволяет пользователям автоматически готовить по выбранному рецепту, не нажимая на кнопку `BAKE!`каждый раз вручную.

==🟣Input==

Область ввода предоставляет удобное пространство для ввода текста или файлов путем вставки, набора текста или перетаскивания для выполнения операций.

Кроме того, он обладает следующими характеристиками:

- `Add a new input tab`Здесь создается дополнительная вкладка, позволяющая пользователю использовать значения, отличные от значений на предыдущей вкладке.

![Откройте новую вкладку «Область ввода» в разделе «Поля ввода».](https://cdn-images.tryhackme.com/user-uploads/6645aa8c024f7893371eb7ac/room-content/6645aa8c024f7893371eb7ac-1728731934218.png)

- `Open folder as input`Эта функция позволяет пользователям загружать целую папку в качестве входного значения.

![В разделе «Область ввода» выберите опцию «Открыть папку в качестве входных данных».](https://cdn-images.tryhackme.com/user-uploads/6645aa8c024f7893371eb7ac/room-content/6645aa8c024f7893371eb7ac-1728731934186.png)  
- `Open file as input`Эта функция позволяет пользователю загружать файл в качестве входного значения.

![В разделе «Область ввода» выберите опцию «Открыть файл в качестве входных данных».](https://cdn-images.tryhackme.com/user-uploads/6645aa8c024f7893371eb7ac/room-content/6645aa8c024f7893371eb7ac-1728731934210.png)  
- `Clear input and output`Эта функция позволяет пользователю очистить все введенные значения и соответствующие им выходные значения.
- `Reset pane layout`Эта функция возвращает интерфейсу инструмента стандартные размеры окна.

==🟣Output==

Область вывода — это визуальное пространство, демонстрирующее результаты обработки данных. Она наглядно отображает результаты любых манипуляций или преобразований, примененных к входным данным, обеспечивая четкое и интуитивно понятное представление обработанной информации.

![Область вывода инструмента CyberChef с множеством опций.](https://cdn-images.tryhackme.com/user-uploads/6645aa8c024f7893371eb7ac/room-content/6645aa8c024f7893371eb7ac-1729081715061.png)  

Функции включают:

- `Save output to file`Эта функция позволяет пользователям сохранять результат в файл с расширением .dat.
- `Copy raw output to the clipboard`Эта функция позволяет пользователям копировать исходный вывод непосредственно в буфер обмена, что дает им возможность быстро скопировать результаты для использования в других приложениях или документах.
- `Replace input with output`Эта функция позволяет пользователям быстро перезаписывать входные данные на основе результатов операций.
- `Maximise output pane`Эта функция возвращает интерфейсу инструмента стандартные размеры окна.

==🔵`Extract IP addresses`== программа извлечет любой действительный IPv4/6-адрес из любого заданного входного значения.

==🔵`Extract email addresses`==извлекает любые строки и символы в формате anything@domain[.]com.

==🔵`Extract URLs`==Извлекает унифицированный указатель ресурса, обычно известный как URL. URL — это адрес, используемый для доступа к ресурсам в интернете.

Временная метка UNIX — это 32-битное значение, представляющее количество секунд с 1 января 1970 года по UTC (эпоха UNIX). Чтобы преобразовать " **Fr Sep 6 20:30:22 +04 2024** " в временную метку UNIX, используйте операции  ==🔵`To UNIX Timestamp`==, где результатом будет `1725654622`. Если вы хотите преобразовать его обратно в более читаемый формат, вы можете использовать  ==🔵`From UNIX Timestamp`==.
