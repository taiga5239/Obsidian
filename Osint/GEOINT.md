==🔴**GEOINT - geospatial intelligence**==

Подразумевает использование геоданных различного характера для исследования активности объекта

GEOINT использует как классические методы OSINT (анализ изображений, соцсетей), так и данные с геоаналитических платформ, геолокационные базы данных и структурированные базы изображений.
Несмотря на то, что GEOINT изначально использовался в военнополитической сфере (официально с 2005), постепенно стал внедряться в коммерческий сектор.
Параллельно развивается geo-marketing, WebGIS как результат интеграции геоинформационных систем.

==🔴Поиск изображений в сети Интернет==

- Поиск по ключевым словам
- Поиск похожих изображений 
- Обратный (реверсивный) поиск изображений 
- Попиксельное сравнение двух изображений 
- Распознавание содержимого (контента) изображений

***Анализ изображений***

- источник; 
- оригинальность изображения, исходное состояние; 
- метаданные (геотеги, никнеймы, оборудование и т.д.); 
- визуальный анализ (ниже); 
- контекст расположения изображения.
 
1. Оригинальность фото (https://tineye.com ) 
2. Метаданные фотографии ( https://www.metadata2go.com ) 
3. Упрощенное редактирование (https://cleanup.pictures/ ) 
4. Улучшить качество фото (https://snapedit.app https://vmake.ai/image-enhancer/)

***Метаданные изображений (EXIF)***

- дата и время создания, изменения и доступа к файлу; 
- данные о местоположении, где файл был создан, такие как GPS-координаты;
- информация о типе и модели устройства, с помощью которого был создан файл;
- имя автора, контактные данные, авторские права и другие сведения; 
- яркость, контрастность, насыщенность, уровни цветов и другие;
- ключевые слова, описания, комментарии и теги.
