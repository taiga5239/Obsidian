[[cli windows]]


**PowerShell** — это мощный инструмент от Microsoft, предназначенный для автоматизации задач и управления конфигурацией. Он сочетает в себе интерфейс командной строки и язык сценариев, построенный на платформе .NET. В отличие от более старых текстовых инструментов командной строки, PowerShell является объектно-ориентированным, что означает, что он может обрабатывать сложные типы данных и более эффективно взаимодействовать с компонентами системы. 

В программировании объект представляет собой элемент со свойствами (характеристиками) и методами (действиями)
Аналогично, в PowerShell объекты являются фундаментальными единицами, которые инкапсулируют данные и функциональность, упрощая управление и обработку информации. Объект в PowerShell может содержать имена файлов, имена пользователей или размеры в качестве данных ( свойства ) и передавать функции ( методы ), такие как копирование файла или остановка процесса.

Командлеты используют единообразную **Verb-Noun** систему именования. Такая структура упрощает понимание того, что делает каждый командлет. Параметр **Verb** описывает действие, а параметр **Noun** указывает объект, над которым выполняется действие. Например:

`Get-Content`: Получает содержимое файла и отображает его в консоли.
`Set-Location`: Изменяет (устанавливает) текущий рабочий каталог.

Чтобы вывести список всех доступных командлетов, функций, псевдонимов и скриптов, которые можно выполнить в текущей сессии PowerShell, можно использовать команду `Get-Command`.

Ещё один важный командлет, который стоит иметь в своём арсенале, — это `Get-Help`: он предоставляет подробную информацию о командлетах, включая использование, параметры и примеры. Это основной командлет для изучения команд PowerShell.

PowerShell включает псевдонимы — сокращения или альтернативные имена для командлетов — для многих традиционных команд Windows. 
Незаменимый инструмент для пользователей, уже знакомых с другими инструментами командной строки, `Get-Alias` он отображает все доступные псевдонимы. Например, `dir`— это псевдоним для `Get-ChildItem`, а `cd`— это псевдоним для `Set-Location`.

Ещё одной важной особенностью PowerShell является возможность расширения его функциональности за счёт загрузки дополнительных командлетов из онлайн-репозиториев.

Для поиска модулей (наборов командлетов) в онлайн-репозиториях, таких как PowerShell Gallery, можно использовать `Find-Module`. 
Иногда, если точное имя модуля неизвестно, может быть полезно искать модули с похожим именем. Этого можно добиться, отфильтровав свойство `Name`и добавив подстановочный знак (\*) к частичному имени модуля.
```
PS C:\Users\captain> Find-Module -Name "PowerShell*"   

Version    Name                                Repository           Description 
-------    ----                                ----------           ----------- 
0.4.7      powershell-yaml                     PSGallery            Powershell module for serializing and deserializing YAML

2.2.5      PowerShellGet                       PSGallery            PowerShell module with commands for discovering, installing, updating and publishing the PowerShell artifacts like Modules, DSC Resources, Role Capabilities and Scripts.                                                   
1.0.80.0   PowerShell.Module.InvokeWinGet      PSGallery            Module to Invoke WinGet and parse the output in PSOjects

0.17.0     PowerShellForGitHub                 PSGallery            PowerShell wrapper for GitHub API  
```

После идентификации модули можно загрузить и установить из репозитория с помощью команды `Install-Module`, что сделает доступными для использования новые командлеты, содержащиеся в модуле.

==🔴Навигация по файловой системе и работа с файлами.== 

`Get-ChildItem` выводит список файлов и каталогов в указанном с помощью -Pathпараметра месте. Ее можно использовать для просмотра каталогов и их содержимого. Если параметр не Path указан, командлет отобразит содержимое текущего рабочего каталога.

Для перехода в другой каталог можно использовать `Set-Location` командлет. Он изменяет текущий каталог, перемещая нас по указанному пути, аналогично команде `cd` в командной строке.

Для создания элемента в PowerShell можно использовать команду `New-Item`. Необходимо указать путь к элементу и его тип (файл или каталог).
```
PS C:\Users\captain\Documents> New-Item -Path ".\captain-cabin\captain-wardrobe" -ItemType "Directory"

   Directory: C:\Users\captain\Documents\captain-cabin

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----          9/4/2024  12:20 PM                captain-wardrobe

PS C:\Users\captain\Documents> New-Item -Path ".\captain-cabin\captain-wardrobe\captain-boots.txt" -ItemType "File"     

   Directory: C:\Users\captain\Documents\captain-cabin\captain-wardrobe

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a----          9/4/2024  11:46 AM              0 captain-boots.txt  
```

Аналогично, `Remove-Item` командлет удаляет как каталоги, так и файлы, тогда как в командной строке Windows у нас есть отдельные команды `rmdir` и `del`.

Мы можем копировать или перемещать файлы и каталоги, используя соответственно `Copy-Item` (эквивалентно `copy`) и `Move-Item` (эквивалентно `move`).

Наконец, для чтения и отображения содержимого файла можно использовать `Get-Content`командлет, который работает аналогично команде `type` в командной строке (или `cat` в системах, подобных Unix).

**==🔴Обработка, фильтрация и сортировка данных==**

**Конвейерная обработка (piping)** — это метод, используемый в средах командной строки, позволяющий использовать выходные данные одной команды в качестве входных данных для другой. Это создает последовательность операций, в которой данные передаются от одной команды к следующей. Конвейерная `|` обработка, обозначаемая символом , широко используется в интерфейсе командной строки Windows

В PowerShell использование конвейерной обработки данных еще более эффективно, поскольку она передает не только текст, но и **объекты** . Эти объекты содержат не только данные, но и свойства и методы, описывающие данные и позволяющие взаимодействовать с ними.

`Sort-Object` командлет для сортировки объектов на основе указанных свойств.

Для фильтрации объектов по заданным условиям и возврата только тех, которые соответствуют критериям, можно использовать `Where-Object` командлет.

Оператор сравнения `-eq` (например, " равно ") входит в набор операторов сравнения , используемых в других языках сценариев (например, Bash, Python).

- `-ne`: " не равно ". Этот оператор можно использовать для исключения объектов из результатов на основе заданных критериев.
- `-gt`: " больше ". Этот оператор отфильтрует только объекты, превышающие указанное значение. Важно отметить, что это строгое сравнение, то есть объекты, равные указанному значению, будут исключены из результатов.
- `-ge`: " больше или равно ". Это нестрогая версия предыдущего оператора. Комбинация `-gt` и `-eq`.
- `-lt`: " меньше, чем ". Как и его аналог "больше, чем", это строгий оператор. Он будет включать только объекты, которые строго ниже определенного значения.
- `-le`: " меньше или равно ". Как и его аналог `-ge`, это нестрогая версия предыдущего оператора. Комбинация `-lt` и -`eq`.

Ниже приведён ещё один пример, демонстрирующий возможность фильтрации объектов путём выбора свойств, соответствующих `-like` заданному шаблону:
```
PS C:\Users\captain\Documents\captain-cabin> Get-ChildItem | Where-Object -Property "Name" -like "ship*"  

   Directory: C:\Users\captain\Documents\captain-cabin

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a----          9/4/2024  12:37 PM           2116 ship-flag.txt 
```

Последним в этом наборе командлетов фильтрации является `Select-String`. Этот командлет ищет текстовые шаблоны в файлах, аналогично командам `grep` в системах на базе Unix или `findstr` в командной строке Windows. Он обычно используется для поиска определенного содержимого в файлах журналов или документах.

**==🔴Информация о системе и сети==**

`Get-ComputerInfo` командлет извлекает исчерпывающую информацию о системе, включая данные об операционной системе, технические характеристики оборудования, сведения о BIOS и многое другое. Он предоставляет снимок всей конфигурации системы в одной команде. Его традиционный аналог `systeminfo` извлекает лишь небольшой набор тех же сведений.

`Get-LocalUser` отображает список всех локальных учетных записей пользователей в системе. По умолчанию для каждого пользователя отображается имя пользователя, статус учетной записи и описание.

`Get-NetIPConfiguration` Предоставляет подробную информацию о сетевых интерфейсах системы, включая IP-адреса, DNS-серверы и конфигурации шлюзов.

В случае необходимости получения подробной информации об IP-адресах, назначенных сетевым интерфейсам, `Get-NetIPAddress` командлет отобразит сведения обо всех IP-адресах, настроенных в системе, включая те, которые в данный момент неактивны.

==🔴Анализ систем в реальном времени==

Для сбора более подробной информации о системе, особенно касающейся динамических аспектов, таких как запущенные процессы, службы и активные сетевые соединения, мы можем использовать набор командлетов, которые выходят за рамки статических сведений о машине.

`Get-Process` Предоставляет подробный обзор всех запущенных в данный момент процессов, включая использование ЦП и памяти, что делает его мощным инструментом для мониторинга и устранения неполадок.

Аналогичным образом, `Get-Service` это позволяет получать информацию о состоянии служб на машине, например, какие службы запущены, остановлены или приостановлены. Он широко используется системными администраторами при устранении неполадок, а также экспертами-криминалистами, ищущими аномальные службы, установленные в системе.

Для мониторинга активных сетевых соединений `Get-NetTCPConnection` отображается текущее количество TCP-соединений, предоставляя информацию как о локальных, так и об удаленных конечных точках. Этот командлет особенно полезен при реагировании на инциденты или анализе вредоносного ПО, поскольку он может выявить скрытые бэкдоры или установленные соединения с сервером, контролируемым злоумышленником.

`Get-FileHash` полезный командлет для генерации хешей файлов, который особенно ценен при реагировании на инциденты, поиске угроз и анализе вредоносного ПО, поскольку помогает проверять целостность файлов и выявлять потенциальные попытки их изменения.

Также вы можете просмотреть альтернативные потоки данных (ADS), прикрепленные к файлу, через PowerShell
```
PS C:\Users\Alex\Documents> Get-Item -Path "C:\House\house_log.txt" -Stream *

PSPath        : Microsoft.PowerShell.Core\FileSystem::C:\House\house_log.txt::$DATA
PSParentPath  : Microsoft.PowerShell.Core\FileSystem::C:\House
PSChildName   : house_log.txt::$DATA
PSDrive       : C
PSProvider    : Microsoft.PowerShell.Core\FileSystem
PSIsContainer : False
FileName      : C:\House\house_log.txt
Stream        : :$DATA
Length        : 13

PSPath        : Microsoft.PowerShell.Core\FileSystem::C:\House\house_log.txt:housinginfo
PSParentPath  : Microsoft.PowerShell.Core\FileSystem::C:\House
PSChildName   : house_log.txt:housinginfo
PSDrive       : C
PSProvider    : Microsoft.PowerShell.Core\FileSystem
PSIsContainer : False
FileName      : C:\House\house_log.txt
Stream        : housinginfo
Length        : 21
```

В приведенном выше выводе вы можете увидеть два потока, прикрепленных к файлу `C:\House\house_log.txt`:

1. `:$DATA` Это поток данных по умолчанию для каждого файла NTFS. Он содержит обычное содержимое файла и не является потоком ADS.

2. `housinginginfo` Альтернативный поток данных (ADS), добавленный к этому файлу, отображается как  house_log.txt:housinginfo, что означает, что к этому файлу прикреплен дополнительный скрытый поток с именем housinginfo

==🔴Скриптинг==

**Скриптинг** — это процесс написания и выполнения последовательности команд, содержащихся в текстовом файле, известном как скрипт, для автоматизации задач, которые обычно выполняются вручную в командной оболочке, например: PowerShell.

`Invoke-Command` Он необходим для выполнения команд на удаленных системах, что делает его основополагающим инструментом для системных администраторов, инженеров по безопасности и специалистов по тестированию на проникновение. `Invoke-Command` Он обеспечивает эффективное удаленное управление и — в сочетании со скриптами — автоматизацию задач на нескольких машинах. Его также можно использовать для выполнения полезных нагрузок или команд на целевых системах во время проверки на проникновение как специалистами по тестированию на проникновение, так и злоумышленниками.

```
PS C:\Users\captain> Get-Help Invoke-Command -examples

NAME
    Invoke-Command
    
SYNOPSIS
    Runs commands on local and remote computers.
    
    ------------- Example 1: Run a script on a server -------------
    
    Invoke-Command -FilePath c:\scripts\test.ps1 -ComputerName Server01
    
    The FilePath parameter specifies a script that is located on the local computer. The script runs on the remote computer and the results are returned to the local computer.

    --------- Example 2: Run a command on a remote server ---------

    Invoke-Command -ComputerName Server01 -Credential Domain01\User01 -ScriptBlock { Get-Culture }

    The ComputerName parameter specifies the name of the remote computer. The Credential parameter is used to run the command in the security context of Domain01\User01, a user who has permission to run commands. The ScriptBlock parameter specifies the command to be run on the remote computer.

    In response, PowerShell requests the password and an authentication method for the User01 account. It then runs the command on the Server01 computer and returns the result.
[...]   
```
Первые два примера, приведенные на `Get-Help` странице «Примеры» и описанные выше, достаточны для понимания простоты и мощи этого `Invoke-Command` командлета.

Первый пример демонстрирует, как этот командлет можно очень легко комбинировать с любым пользовательским скриптом для автоматизации задач на удаленных компьютерах.

Второй пример демонстрирует, что нам не нужно уметь писать скрипты, чтобы воспользоваться всеми преимуществами командлета `Invoke-Command`. Фактически, добавив `-ScriptBlock { ... }` параметр к синтаксису командлета, мы можем выполнить любую команду (или последовательность команд) на удалённом компьютере. Результат будет таким же, как если бы мы вводили команды в локальной сессии PowerShell на самом удалённом компьютере.
