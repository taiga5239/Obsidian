[[Основы эксплуатации]]

Metasploit — наиболее широко используемая платформа для эксплуатации уязвимостей. Это мощный инструмент, который может поддерживать все этапы тестирования на проникновение, от сбора информации до постэксплуатации.

Metasploit имеет две основные версии:

- Metasploit Pro : коммерческая версия, упрощающая автоматизацию и управление задачами. Эта версия имеет графический пользовательский интерфейс.
- Metasploit Framework : версия с открытым исходным кодом, работающая из командной строки. 

*Metasploit Framework* — это набор инструментов, позволяющих собирать информацию, сканировать, эксплойтировать уязвимости, разрабатывать эксплойты, постэксплуатировать уязвимости и многое другое. Хотя основное применение Metasploit Framework сосредоточено в области тестирования на проникновение, он также полезен для исследования уязвимостей и разработки эксплойтов.

Основные компоненты Metasploit Framework можно кратко описать следующим образом:
- msfconsole : Основной интерфейс командной строки.
- Модули : вспомогательные модули, такие как эксплойты, сканеры, полезные нагрузки и т. д.
- Инструменты : Автономные инструменты, которые помогут в исследовании уязвимостей (оценка уязвимости) или для тестирования на проникновение. Некоторые из этих инструментов — msfvenom, pattern_create и pattern_offset. msfvenom мы рассмотрим в этом модуле, но pattern_create и pattern_offset — это инструменты, полезные для разработки эксплойтов.

- ***Эксплойт***: фрагмент кода, использующий уязвимость, присутствующую в целевой системе.
- ***Уязвимость***: ошибка в проектировании, кодировании или логике, затрагивающая целевую систему. Эксплуатация уязвимости может привести к раскрытию конфиденциальной информации или позволить злоумышленнику выполнить код в целевой системе.
- ***Полезная нагрузка***: Эксплойт использует уязвимость. Однако, если мы хотим, чтобы эксплойт дал желаемый результат (получение доступа к целевой системе, чтение конфиденциальной информации и т. д.), нам необходимо использовать полезную нагрузку. Полезная нагрузка — это код, который будет выполняться в целевой системе.

==🔴Основные компоненты metaspoit==

***Auxiliary***
Здесь можно найти любые вспомогательные модули, такие как сканеры, веб-краулеры и фаззеры.
```
tree -L 1 auxiliary/
```

***Encoders***

Кодировщики позволят вам зашифровать эксплойт и полезную нагрузку в надежде, что антивирусное решение, основанное на сигнатурах, сможет их пропустить.

Антивирусные и защитные решения, основанные на сигнатурах, имеют базу данных известных угроз. Они обнаруживают угрозы, сравнивая подозрительные файлы с этой базой данных, и выдают оповещение в случае совпадения. Таким образом, эффективность антивирусных программ может быть ограничена, поскольку они могут выполнять дополнительные проверки.
```
tree -L 1 encoders/
```

***Evasion***

Хотя кодировщики и шифруют полезную нагрузку, их не следует рассматривать как прямую попытку обойти антивирусное программное обеспечение. С другой стороны, модули «обхода» будут пытаться это сделать, с большей или меньшей вероятностью.
```
tree -L 2 evasion/
```

***Exploits***

Уязвимости, аккуратно сгруппированные по целевым системам.
```
tree -L 1 exploits/
```

***NOPs***
Операции NOP (No Operation) буквально ничего не делают. В семействе процессоров Intel x86 они обозначаются кодом 0x90, после которого процессор ничего не делает в течение одного такта. Часто они используются в качестве буфера для обеспечения стабильного размера полезной нагрузки.
```
tree -L 1 nops/
```

***Полезная нагрузка*** (Payload)

Полезная нагрузка — это код, который будет выполняться в целевой системе.
Эксплойты будут использовать уязвимость в целевой системе, но для достижения желаемого результата нам потребуется полезная нагрузка.
Выполнение команд на целевой системе — это уже важный шаг, но наличие интерактивного соединения, позволяющего вводить команды, которые будут выполняться на целевой системе, ещё лучше. Такая интерактивная командная строка называется «оболочкой». Metasploit предоставляет возможность отправлять различные полезные нагрузки, которые могут открывать оболочки на целевой системе.
```
tree -L 1 payloads/
```

В разделе «Полезные нагрузки» вы увидите четыре разных каталога: adapters, singles, stagers и stages.

- Адаптеры: Адаптер оборачивает отдельные полезные нагрузки для преобразования их в различные форматы. Например, обычную полезную нагрузку можно обернуть в адаптер PowerShell, который создаст одну команду PowerShell для выполнения этой полезной нагрузки.
- Однокомпонентные программы: автономные полезные нагрузки (добавление пользователя, запуск notepad.exe и т. д.), для работы которых не требуется загрузка дополнительных компонентов.
- Загрузчики (Stagers): отвечают за установление канала связи между Metasploit и целевой системой. Полезны при работе с загрузкой данных на этапе подготовки. При использовании «загрузчиков на этапе подготовки» сначала загружается загрузчик на целевую систему, а затем загружается остальная часть данных (этап). Это дает некоторые преимущества, поскольку начальный размер данных будет относительно небольшим по сравнению с полным объемом данных, отправленных за один раз.
- Этапы: Загружаются загрузчиком. Это позволит вам использовать полезные нагрузки большего размера.

Metasploit предлагает тонкий способ идентификации отдельных (также называемых «встроенными») полезных нагрузок и нагрузок, размещаемых поэтапно.

- generic/shell_reverse_tcp
- windows/x64/shell/reverse_tcp

Оба являются обратными оболочками Windows. Первый представляет собой встроенную (или одиночную) полезную нагрузку, как указывает символ «\_» между словами «shell» и «reverse». Второй же представляет собой поэтапную полезную нагрузку, как указывает символ «/» между словами «shell» и «reverse».

***Post***

Модули, используемые после взлома, будут полезны на заключительном этапе процесса тестирования на проникновение, описанного выше, после его завершения.
```
tree -L 1 post/
```
