[[Metasploit]]

Meterpreter — расширенная многофункциональная начинка (Payload), которая может быть динамически расширена во время выполнения. В нормальных условиях, это означает, что это обеспечивает Вас основной оболочкой и позволяет Вам добавлять новые особенности к ней по мере необходимости.

==🔴Meterpreter== работает на целевой системе, но не установлен на ней. Он работает в оперативной памяти и не записывает себя на диск целевой системы. Эта функция предназначена для того, чтобы избежать обнаружения во время антивирусного сканирования. По умолчанию большинство антивирусных программ сканируют новые файлы на диске (например, при загрузке файла из интернета), а Meterpreter работает в оперативной памяти RAM. Использование оперативной памяти (Random Access Memory) позволяет избежать необходимости записи файла на диск целевой системы (например, meterpreter.exe). Таким образом, Meterpreter будет рассматриваться как процесс, а не как файл на целевой системе.

Meterpreter также стремится избежать обнаружения сетевыми системами IPS (Система предотвращения вторжений) и IDS системы обнаружения вторжений (IPS и IDS) используют зашифрованную связь с сервером, на котором работает Metasploit (обычно это ваша атакующая машина). Если целевая организация не расшифровывает и не проверяет зашифрованный трафик (например, HTTPS), поступающий в локальную сеть и выходящий из нее, системы IPS и IDS не смогут обнаружить ее активность.

Хотя Meterpreter распознается основными антивирусными программами, эта функция обеспечивает определенную степень скрытности.

Получить представление о доступных версиях Meterpreter, используя команду `msfvenom --list payloads | grep meterpreter`

Ввод команды `help` в любой сессии Meterpreter (отображаемой meterpreter>в командной строке) выведет список всех доступных команд.

Команды — это встроенные инструменты, доступные в Meterpreter. Они будут выполняться в целевой системе без загрузки каких-либо дополнительных скриптов или исполняемых файлов.

Meterpreter предоставит вам три основные категории инструментов;

- Встроенные команды
- Инструменты интерпретатора
- Скриптинг Meterpreter

Если вы выполните help команду, то увидите, что команды Meterpreter перечислены в разных категориях.

- Основные команды
- Команды файловой системы
- Сетевые команды
- Системные команды
- Команды пользовательского интерфейса
- Команды веб-камеры
- Команды вывода звука
- Команды повышения уровня
- Команды базы данных паролей
- Команды временной метки

Основные команды помогут вам ориентироваться в целевой системе и взаимодействовать с ней. Ниже приведены некоторые из наиболее часто используемых.

Основные команды

	background: Запускает текущую сессию в фоновом режиме
	exit: Завершить сессию Meterpreter
	guid: Получить GUID сессии (глобальный уникальный идентификатор)
	help: Отображает меню справки.
	info: Отображает информацию о модуле «Почта».
	irb: Открывает интерактивную оболочку Ruby в текущей сессии.
	load: Загружает одно или несколько расширений Meterpreter.
	migrate: Позволяет перенести Meterpreter в другой процесс.
	run: Выполняет скрипт Meterpreter или модуль Post.
	sessions: Быстро переключиться на другую сессию

Команды файловой системы
	
	cd: Произойдет смена каталога
	ls: Отобразит список файлов в текущем каталоге (также подойдет команда `dir`).
	pwd: Выводит текущий рабочий каталог.
	edit: позволит вам редактировать файл
	cat: Отобразит содержимое файла на экране.
	rm: Удалит указанный файл.
	search: Будет выполнен поиск файлов.
	upload: Загрузит файл или каталог
	download: Загрузит файл или каталог
Сетевые команды

	arp: Отображает хостАРПкэш (протокола разрешения адресов)
	ifconfig: Отображает доступные сетевые интерфейсы в целевой системе.
	netstat: Отображает сетевые подключения.
	portfwd: Перенаправляет локальный порт на удаленный сервис
	route: Позволяет просматривать и изменять таблицу маршрутизации.
Системные команды

	clearev: Очищает журналы событий.
	execute: Выполняет команду
	getpid: Отображает текущий идентификатор процесса
	getuid: Отображает пользователю, что Meterpreter запущен как
	kill: Завершает процесс
	pkill: Завершает процессы по имени
	ps: Отображает список запущенных процессов
	reboot: Перезагружает удалённый компьютер.
	shell: Переход в командную оболочку системы
	shutdown: Выключает удалённый компьютер
	sysinfo: Получает информацию об удалённой системе, например, об операционной системе.
Другие команды (они будут перечислены в разных категориях меню в справочном меню).

	idletime: Возвращает количество секунд, в течение которых удаленный пользователь находился в режиме ожидания.
	keyscan_dump: Выводит содержимое буфера нажатий клавиш
	keyscan_start: Начинает перехват нажатий клавиш
	keyscan_stop: Прекращает перехват нажатий клавиш
	screenshare: Позволяет наблюдать за рабочим столом удаленного пользователя в режиме реального времени.
	screenshot: Делает снимок экрана интерактивного рабочего стола.
	record_mic: Записывает звук с микрофона по умолчанию в течение X секунд.
	webcam_chat: Начинает видеочат
	webcam_list: Список веб-камер
	webcam_snap: Делает снимок с указанной веб-камеры.
	webcam_stream: Воспроизводит видеопоток с указанной веб-камеры.
	getsystem: Попытки возвысить ваши привилегии до уровня привилегий местной системы.
	hashdump: Выводит содержимое базы данных SAM.

Эта `getuid` команда отобразит пользователя, от имени которого в данный момент запущен Meterpreter. Это даст вам представление о вашем возможном уровне привилегий в целевой системе (например, являетесь ли вы пользователем с правами администратора, таким как NT AUTHORITY\SYSTEM, или обычным пользователем?).

`ps` команда выведет список запущенных процессов. В столбце PID также будет указана информация о PID, необходимая для переноса Meterpreter в другой процесс.

Некоторые версии Meterpreter предлагают параметры команд `keyscan_start`, `keyscan_stop`, и , `keyscan_dump` позволяющие Meterpreter работать как кейлоггер. Переключение на другой процесс также может помочь вам обеспечить более стабильную работу Meterpreter. 

Для миграции на любой процесс необходимо ввести команду `migrate`, а затем PID нужного целевого процесса.

`hashdump` команда выведет содержимое базы данных SAM. База данных SAM (Security Account Manager) хранит пароли пользователей в системах Windows. Эти пароли хранятся в формате NTLM ( New Technology LAN Manager) .

`search` команда полезна для поиска файлов, содержащих потенциально важную информацию. В контексте CTF её можно использовать для быстрого поиска файла с флагом или доказательством, а в реальных задачах по тестированию на проникновение может потребоваться поиск файлов, созданных пользователями, или конфигурационных файлов, которые могут содержать пароли или информацию об учетных записях.

`shell` команда запустит обычную командную оболочку на целевой системе. Нажатие CTRL+Z позволит вернуться в оболочку Meterpreter.

На этапе после завершения эксплуатации будет поставлено несколько задач; Meterpreter обладает функциями, которые могут помочь в их достижении.

- Сбор дополнительной информации о целевой системе.
- Ищу интересные файлы, учетные данные пользователей, дополнительные сетевые интерфейсы и в целом интересную информацию о целевой системе.
- Повышение привилегий.
- Боковое движение.

После загрузки любого дополнительного инструмента с помощью `load` команды вы увидите новые параметры в `help` меню.

Для проверки вероятной `shares` созданной пользователем используется модуль  `post/windows/gather/enum_shares`
