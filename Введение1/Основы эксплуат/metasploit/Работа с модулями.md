[[Metasploit]]

Все параметры задаются с использованием одного и того же синтаксиса команд:
`set PARAMETER_NAME VALUE`

При работе с Metasploit вы можете увидеть пять различных приглашений:
- Обычная командная строка: Здесь нельзя использовать команды Metasploit.
- Приглашение msfconsole: msf6 — это приглашение msfconsole. Здесь не задан контекст, поэтому команды, зависящие от контекста, для установки параметров и запуска модулей здесь использовать нельзя.
- Контекстная подсказка: После того, как вы выбрали модуль и использовали команду `set` для его выбора, msfconsole отобразит контекст. Здесь можно использовать команды, зависящие от контекста.
- Подсказка Meterpreter: Meterpreter — это важная полезная нагрузка.  Это означает, что агент Meterpreter был загружен в целевую систему и установил с вами соединение. Здесь вы можете использовать команды, специфичные для Meterpreter.
- Доступ к командной оболочке целевой системы: После завершения эксплойта вы можете получить доступ к командной оболочке целевой системы. Это обычная командная строка, и все команды, введенные здесь, выполняются в целевой системе.

`show options` команда выведет список всех доступных параметров.

К числу часто используемых параметров относятся:

- ***RHOSTS***: «Удаленный хост», IP-адрес целевой системы. Можно указать один IP-адрес или диапазон сетей. Поддерживается обозначение CIDR (бесклассовая междоменная маршрутизация) (/24, /16 и т. д.) или диапазон сетей (10.10.10.x – 10.10.10.y). Также можно использовать файл, в котором перечислены цели, по одной цели на строку, используя file:/path/of/the/target_file.txt, как показано ниже.

- RPORT: “Удаленный порт”, порт на целевой системе, на которой работает уязвимое приложение.
- Payload: Полезная нагрузка, которую вы будете использовать с эксплойтом.
- LHOST: “Localhost”, IP-адрес атакующей машины (вашего AttackBox или Kali Linux).
- LPORT: «Локальный порт», порт, который вы будете использовать для подключения обратной оболочки. Это порт на вашей атакующей машине, и вы можете установить его на любой порт, не используемый никаким другим приложением.
- Session: Каждое соединение, установленное с целевой системой с помощью Metasploit, будет иметь идентификатор сессии. Вы будете использовать его с модулями, запускаемыми после эксплуатации уязвимости, которые будут подключаться к целевой системе, используя существующее соединение.

Также можно очистить значение любого параметра с помощью `unset` команды или очистить все заданные параметры с помощью unset `all` команды.

Вы можете использовать эту `setg` команду для установки значений, которые будут использоваться для всех модулей.
Эта `setg` команда устанавливает глобальное значение, которое будет использоваться до тех пор, пока вы не выйдете из Metasploit или не сбросите его с помощью другой `unsetg` команды.

==🔴Использование модулей==

После установки всех параметров модуля вы можете запустить его с помощью `exploit` команды. Metasploit также поддерживает `run` команду, которая является псевдонимом, созданным для команды `exploit` поскольку слово «эксплойт» не имело смысла при использовании модулей, не являющихся эксплойтами (сканеры портов, сканеры уязвимостей и т. д.).

Вы можете использовать эту `background` команду, чтобы перевести командную строку в фоновый режим и вернуться к командной строке msfconsole.

`sessions` команду можно использовать из командной строки msfconsole или из любого другого контекста для просмотра существующих сессий.
