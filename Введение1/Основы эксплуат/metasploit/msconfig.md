[[Metasploit]]

Консоль Metasploit (msfconsole) можно использовать как обычную командную оболочку. Первая команда — это команда, `ls` которая выводит список содержимого папки, из которой был запущен `Metasploit msfconsole`.

Затем отправляется `ping` на IP-адрес DNS Google (8.8.8.8).

Команда `help` может использоваться как отдельно, так и для вызова конкретной команды.

С помощью команды `history` вы можете просмотреть команды, которые вводили ранее.

Управление Msfconsole осуществляется контекстом; это означает, что если параметр не задан как глобальная переменная, все настройки параметров будут потеряны при изменении используемого модуля.

Используемый модуль также можно выбрать с помощью `use` команды, за которой следует число в начале строки результатов поиска.

Контекст, в котором мы будем работать можно увидеть, введя команду `show options`.
Эта команда выведет параметры, относящиеся к выбранному нами ранее эксплойту. Команда `show options` будет выдавать разные результаты в зависимости от контекста её использования.

В одном примере показано, что для этого эксплойта потребуется установить такие переменные, как RHOSTS и RPORT. С другой стороны, модулю постэксплуатации может потребоваться только установить идентификатор сессии. 
**Сессия** — это существующее соединение с целевой системой, которое будет использовать модуль постэксплуатации.

Эту show команду можно использовать в любом контексте, указав тип модуля (Auxiliary, полезная нагрузка, эксплойт и т. д.), чтобы вывести список доступных модулей.

Вы можете выйти из контекста, используя `back` команду.

Дополнительную информацию о любом модуле можно получить, введя `info` команду в контексте его использования.

Одна из самых полезных команд в msfconsole — это `search`. Эта команда выполнит поиск в базе данных Metasploit Framework модулей, соответствующих заданному параметру поиска. Вы можете проводить поиск, используя номера CVE, названия эксплойтов (eternalblue, heartbleed и т. д.) или целевую систему.

Вывод команды search предоставляет обзор каждого возвращенного модуля. Вы можете заметить, что столбец «имя» уже содержит больше информации, чем просто имя модуля. Вы можете увидеть тип модуля и категорию модуля (сканер, администратор, Windows, Unix и т. д.). Вы можете использовать любой модуль, возвращенный в результатах поиска, с помощью команды `use`, за которой следует число в начале строки результатов
