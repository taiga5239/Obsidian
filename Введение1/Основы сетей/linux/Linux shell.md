[[Linux]]

В большинстве дистрибутивов Linux в качестве оболочки по умолчанию используется **Bash** (Bourne Again Shell). Однако оболочка, отображаемая при открытии терминала, зависит от вашего дистрибутива Linux.

При работе с командной оболочкой необходимо находиться в каталоге, куда вы хотите выполнить операции. По умолчанию, при открытии командной оболочки в большинстве дистрибутивов Linux вы будете находиться в своем домашнем каталоге. Чтобы увидеть текущий рабочий каталог, можно выполнить `pwd`команду `print Working Directory`.

Однако вы также можете сменить каталог. Для этого можно использовать команду `cd` (`change Directory`)

При использовании графического интерфейса операционной системы вы можете видеть содержимое каталога на экране - `ls`.

Чтобы прочитать содержимое файла, вы можете ввести следующую команду в своей командной оболочке: `cat`.

Команда `grep` — очень популярная команда среди пользователей Linux. Эта мощная команда позволяет искать любое слово или шаблон в файле. Предположим, вы хотите найти определенные записи в большом файле. Вы можете использовать команду grep вместе с шаблоном этих записей, и она извлечет их для вас. Она также помогает искать определенное ключевое слово в большом файле.

Как и командная строка PowerShell в Windows ОС, Linux доступны различные типы shell, каждая из которых имеет свои особенности и характеристики.

В разных дистрибутивах Linux установлено несколько оболочек. Чтобы узнать, какую оболочку вы используете, введите следующую команду: `echo $SHELL`

Вы также можете вывести список доступных оболочек в вашей операционной системе Linux. Файл `/etc/shells`содержит все установленные оболочки в системе Linux. Вы можете вывести список доступных оболочек в вашей операционной системе Linux, набрав `cat /etc/shells`в терминале.

Для переключения между этими оболочками вы можете ввести название оболочки, установленной в вашей операционной системе, и она откроется

Если вы хотите навсегда изменить оболочку по умолчанию, вы можете использовать команду: `chsh -s /usr/bin/zsh`. Это сделает эту оболочку оболочкой по умолчанию для вашего терминала.

==🔴Bourne Again Shell==

Bourne Again Shell (Bash) — это оболочка по умолчанию для большинства дистрибутивов Linux. При открытии терминала bash доступен для ввода команд.

- Bash — широко используемая оболочка с возможностями написания скриптов.
- В нем есть функция автозавершения с помощью клавиши Tab, что означает, что если вы находитесь в процессе выполнения команды, вы можете нажать клавишу Tab на клавиатуре. Она автоматически завершит команду на основе возможного совпадения или предложит вам несколько вариантов завершения.
- Bash хранит файл истории и записывает все ваши команды. Вы можете использовать клавиши со стрелками вверх и вниз, чтобы выполнить предыдущие команды, не вводя их заново. Вы также можете ввести команду, `history`чтобы отобразить все ваши предыдущие команды.

==🔴Friendly Interactive Shell==

В большинстве дистрибутивов Linux интерактивная оболочка *Friendly Interactive Shell (Fish)* также не является оболочкой по умолчанию. Как следует из названия, она больше ориентирована на удобство использования, чем другие оболочки. Ниже перечислены некоторые ключевые особенности *fish*:

- Он предлагает очень простой синтаксис, который подходит для начинающих пользователей.
- В отличие от bash, в нем есть функция автоматической проверки орфографии для вводимых вами команд.
- С помощью fish вы можете настроить командную строку, добавив несколько интересных тем оформления.
- Функция подсветки синтаксиса в fish раскрашивает разные части команды в зависимости от их роли, что может улучшить читаемость команд. Это также помогает нам обнаруживать ошибки благодаря их уникальному цвету.
- Fish также предоставляет возможности написания скриптов, автодополнения команд и истории команд, аналогичные оболочкам, упомянутым в этом задании.
