==🔴***Командная строка Windows***==

Вы можете проверить свой путь из командной строки c помощью команды `set`
Приведенный ниже вывод терминала показывает путь, по которому MS Windows будет выполнять команды, как указано в строке, начинающейся с Path=.

Для определения версии операционной системы (ОС) - `ver`

Мы можем выполнить команду `systeminfo`, чтобы вывести различную информацию о системе, такую ​​как информация об ОС, подробные сведения о системе, процессоре и памяти.

Во-первых, если вывод слишком длинный, вы можете перенаправить его через конвейер `more`. Затем вы можете просматривать его постранично, нажимая клавишу пробела.

`cls` - Очищает экран командной строки.

***Устранение неполадок в сети***

Одна из распространенных задач по устранению неполадок — проверка возможности доступа сервера к определенному серверу в Интернете. Синтаксис команды выглядит следующим образом: `ping target_name`. Мы отправляем определенный ICMP-пакет и ждем ответа.

Еще один полезный инструмент для устранения неполадок — это команда `tracert` , что означает «трассировка маршрута» . Эта команда отслеживает сетевой маршрут, пройденный до достижения цели. Не вдаваясь в подробности, она ожидает, что маршрутизаторы на пути уведомят нас, если они отбросят пакет из-за того, что его время жизни (TTL) достигло нуля.

`nslookup` ищет хост или домен и возвращает его IP-адрес.

`netstat` отображает текущие сетевые соединения и прослушиваемые порты. Базовая `netstat` команда без аргументов покажет установленные соединения.

***Работа с файлами***

`type` команда выведет содержимое текстового файла на экран; это удобно для файлов, которые помещаются в окно терминала. Для более длинных текстовых файлов вам может понадобиться команда `more`.

`copy` команда позволяет копировать файлы из одного места в другое.
Аналогичным образом, вы можете перемещать файлы с помощью `move` команды.

Наконец, мы можем удалить файл, используя `del` или `erase`.

Символ подстановки можно использовать \* для ссылки на несколько файлов. Например, copy \*.md C:\Markdown команда скопирует все файлы с расширением md в каталог C:\Markdown. 

***Управление задачами и процессами***

Мы можем вывести список запущенных процессов, используя команду `tasklist`.

Некоторая фильтрация полезна, поскольку ожидается, что выходные данные будут очень длинными. Вы можете проверить все доступные фильтры, отобразив страницу справки с помощью команды `tasklist /?`.

Допустим, мы хотим найти задачи, связанные с `sshd.exe`, мы можем сделать это с помощью команды `tasklist /FI "imagename eq sshd.exe"`. Обратите внимание, что `/FI` используется для установки имени изображения фильтра равным `sshd.exe`.

```
C:\>tasklist /FI "imagename eq sshd.exe"

Image Name                     PID Session Name        Session#    Mem Usage
========================= ======== ================ =========== ============
sshd.exe                      2116 Services                   0      6,992 K
sshd.exe                      2712 Services                   0      7,668 K
sshd.exe                      4752 Services                   0      7,372 K
```

С идентификатором процесса PID как известно, мы можем завершить любую задачу, используя команду `taskkill /PID target_pid`. 

`chkdsk`: проверяет файловую систему и дисковые тома на наличие ошибок и поврежденных секторов.
`driverquery`: Отображает список установленных драйверов устройств.
`sfc /scannow`: Программа сканирует системные файлы на наличие повреждений и, по возможности, восстанавливает их.

Отображение текстовых файлов: `more file.txt`
