[[Администрирование сетей передачи информации (Linux)]]

**BFD** (Bidirectional Forwarding Detection) — это протокол для быстрого обнаружения сбоев на канале связи между двумя сетевыми устройствами. Работает на уровне данных (L2) и может использоваться с различными протоколами маршрутизации (OSPF, BGP, Static Routes) для ускорения сходимости.

Атрибуты для настройки BFD:
1. Таймеры и интервалы • Интервалы отправки (tx) и приема (rx) пакетов (мс) • Минимальный интервал между BFD-пакетами • Множитель для определения времени тайм-аута 
2. Параметры сессии • Создание шаблона с параметрами BFD • Интервал для медленных BFD-сессий (резервный режим) • Настройка аутентификации 
3. Привязка к интерфейсам • Включение BFD на конкретном интерфейсе • Активация BFD для протокола на интерфейсе 
4. Параметры обнаружения • Режим по требованию (пакеты только при необходимости) • Использование эхо-пакетов для проверки • Пассивный режим (не инициирует сессии) 
5. Привязка к протоколам • Включение BFD для всех интерфейсов протокола • Использование BFD для резервирования (Cisco)
