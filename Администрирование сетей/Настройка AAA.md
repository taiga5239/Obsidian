[[Администрирование сетей передачи информации (Linux)]]

AAA (Authentication, Authorization, Accounting) — это архитектура безопасности, которая управляет доступом пользователей к сетевым ресурсам, отслеживает их действия и ведет учет потребления ресурсов.

- **Authentication (Аутентификация)** — проверка подлинности пользователя или устройства. 
- **Authorization (Авторизация)** — определение прав доступа.
- **Accounting (Учет / Ограничение потребления)** — регистрация действий и расхода ресурсов.

**Уровень 4** — только просмотр и базовая диагностика. Позволяет: ping, traceroute, show, telnet, ssh. Не позволяет менять конфигурацию, сохранять настройки, входить в режим конфигурации. 
**Уровень 8** — Доступ к чуть более расширенным командам мониторинга (например, monitor), но без права на изменение конфигурации.  
**Уровень 12** — полный доступ к настройке. Команды: configure, commit, save, set, rollback — то есть можно редактировать, применять и откатывать конфигурацию устройства.

**RADIUS** (Remote Authentication Dial-In User Service) — это протокол для централизованного управления доступом к сети, реализующий архитектуру AAA.

Команда aaa authentication mode break обычно используется для аварийного восстановления доступа к устройству, когда обычная AAAаутентификация не работает. Если её не настроить, то при отказе серверов AAA вернуться к локальной аутентификации будет сложно — может потребоваться физический доступ к устройству и сброс настроек.
