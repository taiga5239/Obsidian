[[Администрирование сетей передачи информации (Linux)]]

**Анонсирование маршрутов** (Route Advertisement) — это процесс распространения информации о доступных сетях между маршрутизаторами с использованием протоколов динамической маршрутизации. 
Анонсирование маршрутов позволяет маршрутизаторам автоматически обмениваться информацией о доступных сетях, что обеспечивает динамическое построение таблиц маршрутизации, оптимизацию путей передачи данных, отказоустойчивость и масштабируемость сети без необходимости ручной настройки каждого маршрута. 
Виды анонсирования маршрутов: 
	• По типу протокола 
	• По способу распространения 
	• По области действия 
	• По типу сети 
	• По формату данных

**Фильтрация** — это процесс контроля и ограничения передачи данных на основе определённых правил или критериев. Фильтрация маршрутов позволяет контролировать распространение информации о сетях в протоколах маршрутизации, что обеспечивает безопасность, оптимизацию трафика предотвращение петель и управление политиками маршрутизации между различными сетями или автономными системами. 
Методы фильтрации маршрутов: 
	• Фильтрация по префиксу (Prefix-list) 
	• Фильтрация по атрибутам (BGP) 
	• Фильтрация через ACL 
	• Distribute-list 
	• Route Filtering (OSPF) 
	• Метрика как фильтр
