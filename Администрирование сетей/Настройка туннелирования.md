[[Администрирование сетей передачи информации (Linux)]]

**GRE (Generic Routing Encapsulation)** — это протокол туннелирования, который позволяет инкапсулировать сетевые пакеты одного протокола внутри пакетов другого протокола.

**IPIP (IP-in-IP)** — это протокол туннелирования, который инкапсулирует один IP-пакет внутри другого IP-пакета. Это один из самых простых методов создания туннелей.

**GRE (Generic Routing Encapsulation)** 
• Универсальный протокол туннелирования 
• Может инкапсулировать ЛЮБЫЕ типы трафика: IP, Ethernet, IPX и др. 
• Добавляет свой заголовок (минимум 4 байта), поддерживает опции вроде контроля целостности и последовательности пакетов 
• Более гибкий, но немного сложнее 
**IPIP (IP-in-IP)** 
• Специализированный протокол только для IP трафика 
• Инкапсулирует IP-пакет внутри другого IP-пакета 
• Очень простой заголовок (обычно 20 байт), нет дополнительных функций 
• Быстрее, но только для IP и без дополнительных возможностей

Default gateway (шлюз последней надежды/шлюз по умолчанию) будет необходим для пересылки пакетов для неизвестных адресов.
