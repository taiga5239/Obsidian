[[Администрирование сетей передачи информации (Linux)]]

IPsec (Internet Protocol Security) — это набор протоколов для обеспечения безопасности данных на сетевом уровне, который предоставляет такие услуги, как аутентификация, целостность и конфиденциальность для трафика IP. Он нужен для создания защищённых соединений между узлами, сетями или шлюзами, позволяя безопасно передавать данные по недоверенным сетям путем шифрования пакетов и проверки их подлинности, что делает его фундаментальной технологией для построения Виртуальных Частных Сетей.

Обмен ключами в IPsec выполняется по протоколу IKE в две фазы: сначала устанавливается защищённый управляющий канал (IKE SA) с использованием алгоритма Диффи-Хеллмана для генерации общего секретного ключа и методов аутентификации (pre-shared keys или цифровые сертификаты), а затем в рамках этого канала согласуются конкретные ключи и параметры безопасности (IPsec SA) для шифрования и аутентификации пользовательского трафика, что обеспечивает конфиденциальность, целостность и аутентичность передаваемых данных

Аутентификация в IPsec обеспечивается через протоколы AH (Authentication Header) и ESP (Encapsulating Security Payload), которые используют HMAC (Hash-based Message Authentication Code) на основе хэшфункций вроде SHA-256 для проверки целостности и источника пакетов, предотвращая подмену и подделку данных, в то время как IKE (Internet Key Exchange) управляет аутентификацией пиров с помощью предварительно разделенных ключей (PSK), цифровых сертификатов или других методов, устанавливая Security Associations (SA) с уникальными ключами для безопасного обмена данными, где в фазе 1 IKE аутентифицируются устройства и обмениваются ключами, а в фазе 2 создаются SA для AH/ESP, после чего каждый пакет снабжается HMAC, который получатель пересчитывает и сравнивает для подтверждения аутентичности.
