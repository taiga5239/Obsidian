[[Администрирование сетей передачи информации (Linux)]]

**Multi-WAN** — это технология, позволяющая одновременно использовать несколько интернет-каналов (например, от разных провайдеров) на одном маршрутизаторе или шлюзе. Основные цели: повышение отказоустойчивости, балансировка нагрузки и суммирование пропускной способности.

Атрибут failover в правилах Multi-WAN используется для обеспечения приоритетного переключения трафика на резервный канал при отказе основного.

Узнать правила для Multi-WAN можно с помощью команды *show ip policy*. Узнать статус интерфейса в процессе Multi-WAN можно с помощью команды *show interface status*.
