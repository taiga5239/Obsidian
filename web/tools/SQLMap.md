[[Web_tools]]

Атака с использованием SQL-инъекций включает в себя обнаружение уязвимости SQL-инъекций в приложении и манипулирование базой данных. Однако выполнение всего этого вручную может занять много времени и усилий.

==🔴SQLMap== - Это автоматизированный инструмент для обнаружения и использования уязвимостей SQL-инъекций в веб-приложениях. Он упрощает процесс выявления этих уязвимостей.

`--help`Команда с SQLMap выведет список всех доступных флагов, которые вы можете использовать. Если вы не хотите вручную добавлять флаги к каждой команде, используйте `--wizard`флаг с SQLMap. При использовании этого флага инструмент будет направлять вас на каждом шаге и задавать вопросы для завершения сканирования, что делает его идеальным вариантом для начинающих.

`--dbs`флаг помогает извлечь все имена баз данных. Получив имена баз данных, вы можете извлечь информацию о таблицах этой базы данных, используя команду `-D database_name --tables`. После получения таблиц, если вы хотите перечислить записи в этих таблицах, вы можете использовать `-D database_name -T table_name --dump`команду.

==🔵Первый шаг== — поиск потенциально уязвимого URL-адреса или запроса. Часто встречаются URL-адреса, использующие GET-параметры для получения данных. Например, URL-адрес, подобный этому, `http://sqlmaptesting.thm/search?cat=1`использует параметр `cat`, принимающий значение  `1`. Если вы видите какое-либо веб-приложение, использующее GET-параметры в URL-адресах для получения данных, вы можете протестировать этот URL-адрес с помощью флага -u в инструменте SQLMap. Это считается тестированием на основе HTTP GET-запросов. Такой подход используется, когда приложение использует GET-параметры в URL-адресе для получения данных из поисковых запросов.

В реальных условиях многие веб-приложения используют файлы cookie для поддержания пользовательских сессий, обеспечения аутентификации или применения контроля доступа. При тестировании таких приложений простого указания URL-адреса для SQLMap может быть недостаточно, поскольку неаутентифицированные запросы могут быть перенаправлены, отклонены или вернуть другое содержимое. SQLMap поддерживает тестирование на основе файлов cookie с помощью флага --cookie, который позволяет включать сессионные файлы cookie.

Чтобы извлечь все имена таблиц определим базу данных после флага `-D`и используем `--tables`флаг в конце

Чтобы выгрузить записи, содержащиеся в таблицах, определим базу данных с помощью  `-D`флага, таблицу с помощью  `-T` флага, а для извлечения записей из таблицы используем `--dump`флаг.  

Вы можете использовать следующую команду, чтобы передать POST запрос, сохраненный в текстовом файле, в инструмент SQLMap: `sqlmap -r intercepted_request.txt`
