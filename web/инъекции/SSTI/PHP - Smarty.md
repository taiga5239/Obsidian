[[SSTI]]

==🔵Smarty== — это мощный шаблонизатор для PHP. Это позволяет разработчикам отделять представление от бизнес-логики, улучшая удобство сопровождения и масштабируемость приложений. Однако возможность выполнения PHP-функций внутри шаблонов может сделать приложения уязвимыми для атак внедрения шаблонов на стороне сервера, если конфигурация не является безопасной.

Внедрите простой тег Smarty, чтобы проверить, будет ли он обработан. Если приложение возвращает "HELLO", это означает, что приложение использует шаблонизатор Smarty. {'Hello'|upper} .

После подтверждения уязвимости сайта к SSTI с помощью Smarty, вы можете создать полезную нагрузку, использующую функции PHP для выполнения системных команд. Одна из наиболее распространенных функций для этого — это функция system() . Использование полезной нагрузки  {system("ls")}является прямым и эффективным способом взлома, если настройки безопасности Smarty разрешают выполнение функций PHP.

==🔴Исправления==

1. Отключение {php} тегов : Убедитесь, что {php}теги отключены в конфигурациях Smarty, чтобы предотвратить выполнение PHP кода внутри шаблонов.
```
$smarty->security_policy->php_handling = Smarty::PHP_REMOVE;
$smarty->disable_security = false;
```
2. Используйте защищенные обработчики : если вам необходимо разрешить пользователям настраивать шаблоны, предоставьте защищенный набор тегов или модификаторов, которые они могут использовать и которые не допускают прямого выполнения команд или доступа к командной оболочке.
3. Регулярные проверки безопасности : Проводите проверки безопасности файлов шаблонов и логики обработки данных, чтобы убедиться в отсутствии небезопасных методов. Регулярно обновляйте Smarty, чтобы получать обновления безопасности.
