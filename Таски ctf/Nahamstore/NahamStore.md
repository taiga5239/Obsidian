[[Решение тасков]]

Комната для поиска уязвимостей и взлома веб-приложений.

Для начала выполнения задания добавил записи в файл /etc/hosts, сначала 
`10.112.164.131 nahamstore.thm`

Перечислил поддомены для http://nahamstore.thm:
`ffuf -w /usr/share/wordlists/SecLists/Discovery/DNS/subdomains-top1million-20000.txt -H "Host: FUZZ.nahamstore.thm" -u http://nahamstore.thm/ -mc 200,204,301,302,307,401,403,405 -fw 125`

И добавил найденные поддомены в /etc/hosts

`dirsearch -u http://nahamstore.thm`
