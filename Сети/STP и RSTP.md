[[Сети и системы передачи информации (L2-3)]]

**STP (Spanning Tree Protocol)** — это протокол, предназначенный для предотвращения петель в Ethernet-сетях.
Включение STP:
[root@host] *ovs-vsctl set bridge ovs0 stp_enable=true*
Проверка состояния протокола связующего дерева на коммутаторе
[root@host] *ovs-appctl stp/show*

**BPDU** — служебные кадры протокола STP и RSTP, используемые для обмена информацией между коммутаторами
В BPDU пакете содержится ID протокола, версия, тип BPDU, приоритет корневого моста, стоимость пути, ID порта отправителя, время с момента генерации BPDU, максимальное время жизни и интервал отправки.
В STP-ролях портов можно увидеть, что порт заблокирован для избежания петель.
[root@host] *ovs-vsctl set bridge ovs0 rstp_enable=true*
Во время работы RSTP протокола можно обнаружить роли: designated, root, disabled.
Для STP в уже сложившейся топологии только корневой коммутатор шлет BPDU, остальные ретранслируют, а для RSTP все коммутаторы шлют BPDU в соответствии с Hello-таймером. Также RSTP имеет всего 3 состояния портов, когда STP имеет 5 состояний. При использовании STP коммутатор, обнаруживший изменение топологии, извещает корневой коммутатор. Тот, в свою очередь, требует от всех остальных очистить их записи о текущей топологии в течение Forward Delay Timer. А при использовании STP обнаружение изменений в топологии влечет немедленную очистку записей.
