[[Сети и системы передачи информации (L2-3)]]

**Bridge** - устройство, которое используется для соединения двух или более сетевых сегментов, а также способное запоминать MAC-адреса пакетов данных, пересылать Ethernet кадры только тогда, когда это нужно и хранить Ethernet кадры для предотвращения коллизии.
[root@host] *ip a*  - отображение настроек сетевых интерфейсов
Настройка моста:
[root@host] *ip link add name bridge type bridge*
[root@host] *ip link set dev ens19 master bridge*
[root@host] *ip link set dev bridge up*
[root@host] *ip link set dev ens19 up*
Проверка конфигурации соединения:
[root@host] *bridge link*
Конфигурационный файл для ip-адреса настраивается по пути
[root@host] *vim /etc/net/ifaces/ens19/ipv4address*
Отправка ICMP пакетов осуществляется через *ping*
**ICMP** - это протокол управления сообщениями в интернете, который используется для передачи сообщений об ошибках, которые возникают при обработке IP-пакетов.
ICMP часто используется для диагностики и тестирования сетевых соединений.
**Широковещательный домен** — это набор сетевых устройств, которые получают широковещательный трафик друг от друга. Широковещательный домен опасен тем, что сообщения могут создавать значительную нагрузку на сеть, сообщения могут быть использованы злоумышленниками для проведения атак, таких как DDoS-атаки, когда злоумышленник отправляет большое количество широковещательных сообщений, чтобы перегрузить сеть. Чтобы снизить нагрузку, воспроизводимую широковещательным трафиком необходимо ограничить размер широковещательных доменов, например, добавить маршрутизатор в сеть, который не пересылает широковещательный трафик. Также можно использовать VLAN (виртуальная локальная сеть), которая позволяет логически разделить сеть на несколько сегментов.
**ARP** – это протокол, используемый для сопоставления IP-адресов с MAC-адресами. В сетях TCP/IP устройства общаются на разных уровнях модели OSI. На сетевом уровне используются IP-адреса, а на канальном уровне — MAC-адреса. Когда устройство хочет отправить данные другому устройству в локальной сети, оно должно знать MAC-адрес получателя. ARP позволяет узнать этот MAC-адрес, зная уже известный IP-адрес. Когда устройство отправляет данные в локальной сети, оно использует MAC-адреса для передачи кадров. Зная только IP-адрес, нельзя отправить данные на физическом уровне, так как устройство не знает, какой MAC-адрес использовать.
Также мост можно настроить с помощью Openvswitch.
Настройка моста и интерфейсов:
[root@host] *ovs-vsctl add-br ovs0*
[root@host] *ovs-vsctl add-port ovs0 ens19*
[root@host] *ovs-vsctl show*
**Switch** - это сетевое устройство, которое используется для соединения различных устройств в локальной сети и управления передачей данных между ними.
Switch в основном работает на канальном уровне L2 модели OSI. На этом уровне коммутатор отвечает за передачу данных между устройствами в локальной сети на основе их MAC-адресов. Но некоторые коммутаторы могут также работать на сетевом уровне L3 модели OSI. Маршрутизирующие коммутаторы могут выполнять функции маршрутизации, что позволяет им обрабатывать IP-адреса и управлять трафиком между различными сетями.
Коммутатор имеет ту же логику моста. Он изучает MAC-адреса, сохраняет кадры Ethernet и пересылает их только при необходимости. Отличие в том, что он намного быстрее использует специализированное оборудование. Мосты обычно имеют меньшее количество портов, обрабатывая данные последовательно, в то время как коммутаторы могут иметь множество портов и обрабатывать данные параллельно.
