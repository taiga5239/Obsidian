[[Сети и системы передачи информации (L2-3)]]

**Базовая настройка связки L2 и L3 технологий** — это фундамент построения корпоративных сетей. Главная задача здесь — разделить сеть на изолированные широковещательные домены на аппаратном уровне (L2) и обеспечить между ними управляемую маршрутизацию (L3).

Sub-интерфейс - виртуальный логический сетевой интерфейс, созданный на базе одного физического сетевого порта.
Он позволяет разделить один физический провод или порт на несколько независимых логических каналов.
- **Привязка к физическому порту:** Один реальный порт (например, `FastEthernet 0/0`) выступает основой. На нем создаются виртуальные «ответвления» с собственными именами и точками входа (например, `fa0/0.10`, `fa0/0.20`). 
- **Тегирование трафика (IEEE 802.1Q):** Каждому sub-интерфейсу назначается свой номер виртуальной сети (**VLAN**), чтобы сетевое устройство понимало, какому логическому каналу адресован конкретный пакет данных.
- **Маршрутизация (Inter-VLAN):** Sub-интерфейсы часто используют на роутерах для связи между разными VLAN без покупки отдельного физического маршрутизатора для каждой сети (схема _Router-on-a-Stick_).
[root@host] *ip link add link ens19 name ens19.100 type vlan id 100*
[root@host] *ip link add link ens19 name ens19.200 type vlan id 200*

Добавление адресации на sub-интерфейсах
[root@host] *ip addr add ip_address dev ens19.100*
[root@host] *ip addr add ip_address dev ens19.200*
