[[Сети и системы передачи информации (L2-3)]]

**VLAN** - это виртуальные локальные сети, использующиеся для эффективного разделения сетей.
Установка тегирования на виртуальных интерфейсах ens19 и ens20.
[root@host] *ovs-vsctl set port ens19 tag=10*
[root@host] *ovs-vsctl set port ens20 tag= 20*
[root@host] *ovs-vsctl show*
Через интерфейсы с разными тегами трафик не идет.
**Trunk порты** - это порты, способные передавать трафик нескольких VLAN одновременно. 
То есть с помощью протокола 802.1Q коммутаторы при обработке кадров будут учитывать не только MAC-адрес устройства, но и номер VLAN в теге кадра, который сравнивается с номером VLAN в таблице. 
**Native порты** - это порты, способные обрабатывать нетегированный трафик.
Назначение режима работы “Native-untagged” на интерфейсе:
[root@host] *ovs-vsctl set port ens19 vlan_mode=native-untagged  tag= 10*
После настройки Native VLAN кадры, теги которых сопадают, идут нетегированными, то есть заголовок 802.1q пропадает. Теги кадров не совпадают с тегами на интерфейсах коммутаторов, поэтому появляется протокол 802.1q.
