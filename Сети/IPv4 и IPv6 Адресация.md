[[Сети и системы передачи информации (L2-3)]]

**IPv4** — это четвёртая версия интернет-протокола, которая лежит в основе передачи данных в большинстве компьютерных сетей.
**IPv6** — это шестая версия интернет-протокола, разработанная для замены IPv4 с целью решить проблему нехватки IPадресов и улучшить производительность, безопасность и масштабируемость сетей.
IPv4 и IPv6 могут работать вместе. Это используется у провайдеров интернета, в крупных компаниях, мобильных сетях, облачных сервисах.
Настройка статических маршрутов:
[root@host] *ip r add default via ..*
Разрешить пересылку пакетов с одного интерфейса на другой можно с помощью команды – net.ipv4.ip_forward 1.
IPv6-адрес представляет собой 128-битную метку, состоящую из 8 групп по четыре шестнадцатеричные цифры, разделенные двоеточиями (например: `2001:0db8:85a3:0000:0000:8a2e:0370:7334`)
IPv4 и IPv6 могут работать вместе. Это используется у провайдеров интернета, в крупных компаниях, мобильных сетях, облачных сервисах.
